# 拍摄 SOP

* [智能望远镜首拍与数据交接](智能望远镜首拍与数据交接.md) - 在首拍或版本更新后记录 App/固件、现场状态、导出文件和可回退证据，不依赖某个固定菜单。
* [城市阳台首次深空拍摄](城市阳台首次深空拍摄.md) - 在城市光害、建筑遮挡和可能看不见北极星的条件下，先完成安全、天空开口、目标选择和测试帧验收。
* [导星](%E5%AF%BC%E6%98%9F.md) - 监测导星星并向赤道仪发送修正，以减小可补偿的跟踪误差；不能消除场旋转、失焦或所有大气影响。
* [对焦方法](%E5%AF%B9%E7%84%A6%E6%96%B9%E6%B3%95.md) - 在当晚视宁度、光学、采样与跟踪条件下寻找可重复的最佳焦点，并用曲线与连续原片验收。
* [极轴校准](%E6%9E%81%E8%BD%B4%E6%A0%A1%E5%87%86.md) - 用极轴镜、板解或漂移法对准赤经轴，并按实际焦距、曝光和主相机星点验收残余误差。
* [拍摄序列计划](%E6%8B%8D%E6%91%84%E5%BA%8F%E5%88%97%E8%AE%A1%E5%88%92.md) - N.I.N.A 序列可编排冷却、停泊/解锁、解析居中、导星、抖动、自动复焦与翻转；只有供电、运动包络和人工接管已验证后才考虑无人值守。
* [采集参数试拍与总积分](%E9%87%87%E9%9B%86%E5%8F%82%E6%95%B0%E8%AF%95%E6%8B%8D%E4%B8%8E%E6%80%BB%E7%A7%AF%E5%88%86.md) - 用相机模式、实测背景、星点、开销和合格帧积分比较增益、偏置、单张曝光与抖动策略。
* [板解、翻转与任务恢复](%E6%9D%BF%E8%A7%A3%E3%80%81%E7%BF%BB%E8%BD%AC%E4%B8%8E%E4%BB%BB%E5%8A%A1%E6%81%A2%E5%A4%8D.md) - 将板解居中、子午线翻转、重新对焦/导星和失败后的停机或人工接管组织为可验收的恢复闭环。
* [现场搭建流程](%E7%8E%B0%E5%9C%BA%E6%90%AD%E5%BB%BA%E6%B5%81%E7%A8%8B.md) - 从选址与安全、供电检查、装机与光路，到线缆干跑、对焦、极轴、导星和测试帧的现场标准流程。
* [校准帧规范](%E6%A0%A1%E5%87%86%E5%B8%A7%E8%A7%84%E8%8C%83.md) - 校准帧用于修正传感器与光路的系统误差：暗场(Dark)去热噪/偏置、平场(Flat)去暗角与灰尘阴影、偏置(Bias)去读出噪声、暗平场(Dark Flat)去平场里的噪声。
* [校准帧现场速查卡](校准帧现场速查卡.md) - 将校准帧匹配关系、拍摄时机、重拍条件和最小验收压缩成拆机前可执行清单。
* [供电、线缆与现场运行安全](%E4%BE%9B%E7%94%B5%E3%80%81%E7%BA%BF%E7%BC%86%E4%B8%8E%E7%8E%B0%E5%9C%BA%E8%BF%90%E8%A1%8C%E5%AE%89%E5%85%A8.md) - 按设备手册建立电源清单、带载验证压降和线缆运动包络，并定义异常时的安全停机边界。
* [数据管理、命名、备份与可复现归档](%E6%95%B0%E6%8D%AE%E7%AE%A1%E7%90%86%E3%80%81%E5%91%BD%E5%90%8D%E3%80%81%E5%A4%87%E4%BB%BD%E4%B8%8E%E5%8F%AF%E5%A4%8D%E7%8E%B0%E5%BD%92%E6%A1%A3.md) - 保存原始数据、会话清单、校验信息、处理配方和独立备份，使项目可恢复、可追溯、可复处理。
