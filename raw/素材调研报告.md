## 01-新人入门

### 新手预算与器材路线 <a id="01-新人入门-新手预算与器材路线"></a>

> 难度：新手 ｜ 读者：准备购买第一套深空器材、预算在 3000 元到 5 万元以上不同档位的新手 ｜ 标签：#器材 #入门 #拍摄

**摘要**：深空摄影是系统工程，第一优先级永远是把钱花在赤道仪（跟踪稳定性）上，而非单反或望远镜。预算从约 3000 元的星野/固定镜头体验，到 1 万级‘赤道仪+APO+单反’入门，再到 3 万级‘谐波赤道仪+制冷彩色(OSC)相机’主力，5 万以上走大口径牛反/RC+单色相机+全套窄带的高级路线。折射 APO 是新手最省心选择；OSC 彩色相机比单色(Mono)门槛低得多，建议新手先 OSC。

**适用场景 / 前置条件**：在买器材前先确定：主要拍摄地（城市光害/郊野暗空）、目标类型（广域星云还是小星系）、是否能接受电脑/控制器的学习成本。再按预算选‘够用且平衡’的组合，避免头重脚轻（好相机配弱赤道仪必然拖线）。

**核心知识点**
- 总原则：赤道仪载重建议 ≥ 整套器材总重的 2 倍（经验值‘载荷约一半留余量’），三脚架承重 ≥ 设备总重 2 倍。
- 折射 APO vs 牛反/RC：APO（如 RedCat 51 / 71F / GT71）轻便、无色散、免调校、几乎免维护，最适合新手；牛反（Newtonian）和 RC 口径大、便宜、集光力强但需彗差改正镜、易受热平衡与光轴准直影响，维护成本高，建议进阶再上。
- OSC（彩色，一次出彩）vs 单色 Mono（需滤镜轮+LRGB/窄带，多通道合成）：新手强烈建议先 OSC，学习成本低；Mono 画质上限高（尤其窄带），但操作与后期复杂，建议有经验后转。
- 约 3000 元档（体验/星野向）：入门单反/微单 + 广角镜头（如 14–35mm）+ 稳固三脚架，拍银河/星座；深空尚未成形，仅作兴趣试探。
- 约 1 万元档（深空入门，单反路线）：轻量赤道仪（如信达 Star Adventurer 星野 tracker，或 iOptron HAE16C 级谐波赤道仪）+ 小 APO（RedCat 51：51mm/f4.9/250mm 或 Evostar 72ED）+ 改机单反（如 Canon Rebel T7 / Nikon D3400）+ 可选光害滤镜（L-Pro）。先不配导星也能练手。
- 约 3 万元档（主力 OSC 路线）：谐波赤道仪（ZWO AM5 载重约 13kg / 无配重，或 HEQ5 级）+ 75–80mm 级 APO（如 Askar 75Q / GT81）+ 制冷彩色相机（ZWO ASI2600MC Pro 或 ATR585C，制冷低于环境 -35℃ 以上，QE 高）+ 50mm 导星镜+导星相机（如 ASI120MM mini）+ 智能控制器（ASIAIR / StellaVita）+ L-Pro 或 L-Extreme 滤镜 + 12V 电源 + 加热带。
- 约 5 万元以上档（进阶/单色窄带路线）：重型赤道仪（EQ6-R Pro 载重约 20kg / AM5+配重或更大）+ 大口径牛反/RC（如 8 寸 RC，需彗差改正/准直）+ 单色制冷相机（ASI2600MM Pro）+ 滤镜轮 + LRGB + 窄带 Hα/OIII/SII 滤镜组 + 电调焦 EAF + OAG 内导星 + 全电脑流程（N.I.N.A + PHD2）。
- 新手可先从‘智能镜/智能相机’（如 ZWO Seestar S50、DWARF 3）以较低成本体验出片，再决定投入全套器材。

**注意事项**
- 不要买‘大口径但弱跟踪’的组合：赤道仪是地基，跟踪差一切白搭。优先把预算给赤道仪。
- APO 镜并非越贵越好，新手 51–80mm 级足够；盲目上大口径折射会迅速拉爆预算且对赤道仪要求更高。
- 单色相机(Mono)需要滤镜轮+多组滤镜+更复杂的拍摄/后期流程，新手直接上易劝退，建议 OSC 起步。
- 单反相机拍校准帧（暗场/偏置）时温度难与现场一致，校准质量不如制冷天文相机；若认真玩深空，制冷相机是更优解。
- 电源必须满足所有设备总电流，尤其赤道仪；建议 12V 锂电池（如 TalentCell 类）续航 4 小时左右并留余量。
- 城市光害下优先选发射星云+窄带/光害滤镜（L-Extreme、L-Ultimate），暗弱星系与反射星云受限。

**示例**
- 1 万档示例组合：iOptron HAE16C（约 2.6kg 本体，载重 8.2kg）+ RedCat 51（51mm/250mm/f4.9）+ 改机 Canon Rebel T7 + L-Pro 滤镜 + 三脚架。
- 3 万档示例组合：ZWO AM5 + Askar 75Q + ZWO ASI2600MC Pro + 50mm 导星镜 + ASI120MM mini + ASIAIR + L-Extreme + 12V 电源 + 加热带。
- 5 万+ 示例组合：EQ6-R Pro + 8 寸 RC + ASI2600MM Pro + 滤镜轮 + LRGB + Hα/OIII/SII 窄带 + EAF + OAG + N.I.N.A/PHD2。

### 深空摄影是什么 <a id="01-新人入门-深空摄影是什么"></a>

> 难度：新手 ｜ 读者：刚接触天文摄影、想了解深空方向的新手 ｜ 标签：#入门 #拍摄 #器材

**摘要**：深空天文拍摄（DSO AP）是用赤道仪长时间跟踪、配合望远镜与制冷相机，专门拍摄星云、星系、星团等太阳系外暗弱天体的摄影门类。它与行星摄影（拍太阳系内行星，靠幸运成像/高帧率）和星野摄影（带地景的广域银河与星座）在目标、器材与后期思路上都有明显区别。

**适用场景 / 前置条件**：当你想要把肉眼看不见的遥远天体记录下来（如M42猎户座大星云、M31仙女座星系、M45昴星团），就需要进入深空摄影。它对环境（光害、跟踪精度）和操作（极轴、导星、叠加）要求明显高于星野，但低于行星摄影对大气稳定性的苛刻要求。

**核心知识点**
- 定义：使用赤道仪跟踪+望远镜+相机，对单一深空天体做多张长时间曝光（单张通常 3–10 分钟）并叠加，提升信噪比，呈现暗弱结构。
- 按目标分类（太阳系外天体）：星云（发射/反射/暗星云，如M42、M8）、星系（如M31、M51、M81/M82）、星团（疏散星团如M45、球状星团如M13）。
- 与行星摄影区别：行星拍太阳系内目标（月、木星、土星等），用短焦距+高帧率幸运成像（每秒数十~上百帧，挑最佳叠加），对大气视宁度极敏感；深空拍暗弱延展天体，靠长曝光+窄带/宽带滤镜+跟踪，对极轴与导星精度敏感。
- 与星野/广域银河摄影区别：星野以广角镜头（14–35mm）拍带地景的银河、星座、流星，曝光短（单张数秒~数十秒）、多张堆栈降噪；深空则以望远镜（数百~上千mm焦距）拍小视场目标，曝光长、需赤道仪跟踪。
- 核心系统四大件：赤道仪（地基，决定跟踪成败）> 望远镜（聚光之眼）> 相机（信号中转）> 导星系统（修正跟踪误差）；外加滤镜、控制软件、电源。
- 常见误区：以为‘相机最贵最重要’——实际赤道仪（跟踪稳定性）才是第一投资优先级，买错最易星点拖线、浪费晴夜。

**注意事项**
- 不要把深空（长曝光叠加）与行星（短曝光幸运成像）的器材与流程混用：行星用的高倍目镜/行星相机不适合深空的长曝光暗弱目标。
- 不要把星野的广角银河思路直接套到深空：深空需要赤道仪跟踪，手持或固定三脚架无法拍好星云/星系。
- 城市光害下并非不能拍深空，但需窄带/光害滤镜，且暗弱星系、反射星云效果受限；优先选发射星云（含Hα/OIII）目标。
- 新手极易低估‘跟踪精度’（极轴+导星）的重要性，导致星点拖线；望远镜和相机再好也救不回拖线画面。[不确定]部分入门文章对‘深空能否用单反手持’表述不一，结论以‘必须赤道仪跟踪’为准。

**示例**
- 典型深空目标示例：M42 猎户座大星云（发射星云）、M31 仙女座星系（旋涡星系）、M45 昴星团（疏散星团）、M13 武仙座球状星团。
- 典型拍摄参数（入门APO+OSC）：焦距 250–500mm、单张曝光 120–300s、增益中等、制冷至 0℃（或低于环境 -15℃ 以上）、累计曝光 2–10 小时。
- 与行星对比：木星拍摄用行星相机 + 2x~3x 巴洛 + 短曝光高帧率（如 1000 帧/段，每段数秒）幸运成像，深空则完全相反。

### 从零到出片学习路径 <a id="01-新人入门-从零到出片学习路径"></a>

> 难度：新手 ｜ 读者：已购入或准备购入第一套深空器材、希望按阶段系统学会‘拍出第一张干净深空照片’的新手 ｜ 标签：#入门 #拍摄 #软件 #后期

**摘要**：建议分四阶段学习：① 先搞懂基础概念与器材连接；② 掌握架设与极轴校准（决定星点是否圆）；③ 攻克对焦、构图、导星与拍摄序列；④ 学会校准帧（暗/偏置/平场）与叠加、基础后期出片。关键操作顺序：极轴 → 平衡 → 对焦 → 导星 → 拍摄亮场 → 叠加。先用 OSC+智能控制器降低学习成本，再逐步深入。

**适用场景 / 前置条件**：适合已完成器材选购、能在至少一个晴夜连续操作 2–4 小时的环境。建议先在白天/傍晚完成粗对焦、线缆连接、设备平衡等准备，夜间只做精调与拍摄，避免手忙脚乱。

**核心知识点**
- 阶段一·概念与准备：理解赤道仪跟踪原理、天体坐标（赤经/赤纬）、极轴含义、焦距/像素对应的视场与采样；白天练习器材组装、线缆规划、粗对焦、平衡。
- 阶段二·极轴校准（最重要的一步）：先用指极镜/电子极轴镜做粗对极轴，再用软件精对（如 ASIAIR 极轴校准、SharpCap 极轴助手、含漂移法）；极轴误差大会导致星点拖线、场旋。目标：误差 ≤ 几角分以内。
- 阶段三·对焦与导星：用巴式遮光罩（Bahtinov Mask）或电调焦+EAF 做精确对焦（看最细星点）；用 50mm 导星镜+导星相机配合 PHD2/ASIAIR 导星，目标 RMS ≤ 1″（视焦距与像元，通常 <1–2″ 即可出圆星）；开启导星后再拍亮场。
- 阶段四·拍摄与校准帧：现场拍摄顺序建议——开机先制冷 → 平场(20–50张) → 偏置(20–50张) → 暗场(5–20张，与亮场同曝光同温度) → 亮场（单张 3–10 分钟，累计 2–10 小时）。亮场单张曝光一般 120–300s，增益取中等。
- 阶段五·叠加与后期：用校准帧先校正亮场（暗场减暗电流、平场校正渐晕与灰尘、偏置去读出噪声），再星点对齐叠加（软件如 PixInsight、Siril、深空盒子内置流程、Registar）；叠加后做拉伸（ScreenTransferFunction/直方图拉伸）、降噪、色彩与对比调整出片。
- 推荐软件栈：采集控制 ASIAIR / N.I.N.A / APT；导星 PHD2；叠加与后期 PixInsight / Siril（免费）/ AstroPixelProcessor。
- 学习节奏：先出‘第一张干净不拖线的单目标’（如 M42、M31），再追求总曝光时长与窄带多通道；不要一上来就挑战小星系或单色窄带。

**注意事项**
- 极轴没对好就开拍=大概率拖线废片，务必把极轴作为每夜第一步且反复确认。
- 校准帧必须与亮场‘同曝光时间、同温度、同增益’（暗/偏置尤其重要），否则校准失效；制冷相机务必提前开机降温。
- 不要省略平场：镜头/传感器的灰尘与渐晕会让画面出现暗角与脏点，后期难补。
- 导星 RMS 过大（如 >2–3″）时先查极轴、平衡、线缆牵绊与导星星选择，而非盲目加曝光。
- 新手不要在满月/大光害下硬拍暗弱目标；月相参考：新月前后拍暗星云/星系，上/下弦月拍亮星团，满月拍行星/月面。
- 单反相机因现场温度难一致，暗场/偏置质量受限，认真玩建议尽早换制冷相机。
- 避免‘只拍不学后期’：深空照片的‘惊艳感’80%来自叠加与拉伸，原始亮场灰蒙蒙属正常。

**示例**
- 首夜实操顺序示例：架三脚架+赤道仪 → 粗对极轴 → 装镜与相机、接线 → 开机制冷至 0℃ → 软件精对极轴 → 巴式罩粗/精对焦 → 接导星、PHD2 校准并导星(RMS<1″) → 设序列（单张180s×60张，增益100）开拍 → 结束前/后补暗场与平场。
- 新手友好目标：M42 猎户座大星云（冬季明亮、易构图）、M31 仙女座星系（秋季大视场）、M45 昴星团（广域）。
- 示例参数（APO 250–500mm + OSC 制冷相机）：制冷 0℃（或低于环境≥15℃）、增益中等、单张 120–300s、累计 2–6 小时、导星 RMS 目标 <1–2″。

## 02-器材百科

### 关键附件 <a id="02-器材百科-关键附件"></a>

> 难度：新手 ｜ 读者：主镜+赤道仪+相机已就位，需要补齐光学校正、导星、对焦与供电链路的新手 ｜ 标签：#器材 #附件 #减焦镜 #平场镜 #OAG #导星镜 #电调焦 #供电 #USB集线器

**摘要**：关键附件决定出图成败：减焦镜/平场镜校正像场并提速；OAG 与导星镜二选一（长焦优先 OAG 防挠曲）；电调焦(EAF)保证合焦稳定；供电用 12V 锂电池+足流；USB 用带供电集线器集中管理。任一环节不稳都会让长曝光报废。

**适用场景 / 前置条件**：用于固定台址长曝光深空系统的最终集成。主光学与跟踪确定后，需解决像场平整、导星、精准合焦与现场供电布线。

**核心知识点**
- 减焦镜(0.8x Reducer)：缩短焦距、降低焦比（如 f/7→f/5.6），提速并 widening 视场；常与平场镜一体(Reducer/Flattener)。
- 平场镜(Field Flattener)：矫正折射镜边缘像场弯曲，使全幅星点圆润；牛顿需 Coma Corrector(彗差校正)，RC 通常自带平场但仍建议确认。
- OAG vs 导星镜：OAG 从主光路分光导星，与主镜共光轴、无挠曲(flexure)，适合长焦(>1000mm)与重负载；导星镜独立、安装简单、对短焦折射友好，但长焦下易因镜筒挠曲导致导星失准。
- 导星相机：用小像素导星 CMOS（如 ASI120MM Mini / ASI174MM Mini / ASI290MM），配合 PHD2 软件；OAG 需足够亮的导星(通常要求能找到 8–10 等导星)。
- 电调焦(EAF)：电机化调焦（如 ZWO EAF），配合 ASIAIR/电脑做自动对焦与温度补偿，避免热胀冷缩脱焦；支持手动或绝对位置。
- 供电：系统 12V DC 为主；典型峰值电流：赤道仪≈1–3A、冷冻相机≈2–4A(制冷峰值)、导星/电调焦/集线器≈1A、dew heater≈1–2A；总需预留 8–12A，用 12V 锂电池/LiFePO4（如 12V 20Ah–40Ah）。
- 线材与 USB 集线器：用带独立供电的 USB 3.0 集线器（相机 USB3、导星 USB2 可分开），线长留余量并用绑带固定防缠绕；信号线远离供电线减少干扰。
-  dew heater(除露带)：主镜/导星镜前组加加热带+控制器防结露，是夜拍必备。

**注意事项**
- 减焦镜/平场镜必须匹配主镜型号与后截距，否则合焦距不对、星点崩边。
- OAG 找不到亮导星时（窄视场）会导星失败，此时改回导星镜或换亮天区。
- 导星镜与主镜热膨胀不同步，长焦下单独特星镜挠曲会让星点拉线——长焦优先 OAG。
- 供电容量不足：电池放电截止导致半夜掉电，按总电流×时长×1.5 倍余量选 Ah。
- USB 集线器不带电会带不动相机/硬盘，导致掉线；优先有源(AC/DC 供电)集线器。
- 线材拖地/被脚绊：长曝光中拉扯会瞬间报废整组，布线后固定并绕开行走区。
- EAF 安装前确认对焦齿圈兼容，且不影响滤镜轮后端距离。

**示例**
- 折射提速：Sky-Watcher 0.85x Reducer/Flattener 配 Esprit 100ED；锐星/Askar 原厂 0.8x 减焦平场镜。
- 导星方案 A(OAG)：ZWO OAG + ASI120MM Mini 导星相机（长焦 RC/折反首选）。
- 导星方案 B(导星镜)：60mm 导星镜 + ASI290MM Mini（短焦折射便携之选）。
- 电调焦：ZWO EAF 电动调焦器（配 ASIAIR 自动对焦）。
- 供电：12V 40Ah LiFePO4 锂电池 + 点烟器/DC 分配；带供电 7口 USB3.0 集线器；主镜 60mm 除露带+控制器。

### 天文相机选型 <a id="02-器材百科-天文相机选型"></a>

> 难度：进阶 ｜ 读者：准备购买第一台深空冷冻相机，或想从 OSC 升级到单色系统的进阶玩家 ｜ 标签：#器材 #相机 #CMOS #OSC #单色 #冷冻相机 #采样定理 #读出噪声

**摘要**：深空首选冷冻 CMOS（制冷至 -10°C 以下压制暗电流）。OSC(彩色)上手快、一步出彩；单色+滤镜轮分辨率与灵敏度更高但流程更繁。选型看像素尺寸与采样（像元视场≈206×像素μm/焦距）、满井容量与读出噪声（越低越好，配合高增益弱光占优）。代表：ZWO ASI2600/294/533、QHY268/600。

**适用场景 / 前置条件**：已确定主镜与赤道仪，需选传感器。深空长曝光对热噪声敏感，必须制冷；行星/月球可用非制冷小像素高速相机（如 ASI178/462）。

**核心知识点**
- OSC vs 单色：OSC 内置 Bayer 彩色滤镜，一次曝光得彩图、流程简单、总时间短；单色需 LRGB/窄带轮替拍摄，灵敏度更高、分辨率更高(无 Bayer 插值损失)、可窄带，但工作量约 3–5 倍。
- 冷冻 vs 非冷冻：深空用制冷 CMOS（二/三级半导体制冷，可达 -10°C 至 -40°C），暗电流随温度指数下降；非制冷相机热噪声显著，仅适合行星/短曝光。
- 采样定理：像元视场(″/像素)=206.265×像素尺寸(μm)/焦距(mm)；理想采样约为当地视宁度(seeing)的 1/2（如 seeing 2–3″ → 目标 1.0–1.5″/像素）以符合奈奎斯特。
- 像素尺寸权衡：小像素(2.9–3.76μm)高分辨率但需长焦；大像素(4.63μm+)对seeing宽容、弱光大像元占优。可借减焦/增距镜调节有效焦距来匹配。
- 满井容量(Full Well)：单像素可容纳电子数，越大动态范围越高（如 50k–73k e-）；配合『满井模式』高增益可压低读出噪声。
- 读出噪声(Read Noise)：CMOS 现代可低至 1 e- 量级（高增益），决定弱信号 detection 下限；用『最佳增益』(Unity Gain 附近)平衡噪声与动态范围。
- ADC 位深：16-bit(如 IMX571/455)动态范围优于 12/14-bit；位深影响可记录的明暗层次。
- 量子效率(QE)：背照式(BSI)传感器 QE 高（>80%），集光更高效。

**注意事项**
- 不要像素越小越好：过小像素在一般视宁度下只是放大噪声、无细节收益，且文件暴涨。
- 忽略制冷：非制冷相机深空长曝光热噪严重，后期难去除。
- 增益设置：过低增益读出噪声大、过高增益满井骤降动态范围受损；参考厂商『增益-满井-读出噪声』曲线选最佳增益。
- OSC 配窄带需双窄带滤镜：普通 L 宽滤镜在光污染下无效；单色才适合单线窄带。
- 传感器尺寸须被主镜平场覆盖：大传感器(如 2600 的 APS-C 28.3mm 对角)需主镜像圈≥该尺寸，否则边角星点崩坏。
- 确认后端距离(back focus)与滤镜轮/OAG 叠加后的机械长度匹配。

**示例**
- ZWO ASI2600MC/MM Pro：Sony IMX571，APS-C 26.1MP(6248×4176)，像素 3.76μm，满井≈73,000e-，读出噪声可低至≈1.1e-(高增益)，16-bit，制冷。MC=彩色，MM=单色。
- ZWO ASI294MC/MM Pro：Sony IMX294，11.7MP(4144×2822)，像素 4.63μm，满井≈63,700e-，读出噪声低至≈1.2e-，大像元适合视宁度一般环境。
- ZWO ASI533MC/MM Pro：Sony IMX533，9MP 方形(3008×3008)，像素 3.76μm，满井≈50,000e-，读出噪声≈1.1e-，零辉光(amp glow)，适合单反替代。

### 滤镜系统 <a id="02-器材百科-滤镜系统"></a>

> 难度：进阶 ｜ 读者：已用单色或 OSC 相机、想系统化提升出图质量与抗光污染能力的进阶玩家 ｜ 标签：#器材 #滤镜 #LRGB #窄带 #Ha #OIII #SII #双窄带 #光污染

**摘要**：滤镜分宽带(LRGB，用于彩色合成与细节)与窄带(Ha 656.3nm / OIII 500.7nm / SII 671.6nm，只放行发射线)。窄带能在光污染下拍星云，靠『极窄通带』滤除钠灯/汞灯等广谱人工光源。OSC 用双窄带(如 L-eXtreme)一步得伪彩；单色用 LRGB+窄带轮替。选滤镜尺寸须覆盖传感器对角线。

**适用场景 / 前置条件**：用于深空星云/星系成像。LRGB 在暗空出真彩；窄带在光污染城市或拍发射星云(HII区、行星状星云、超新星遗迹)时不可或缺。需配合滤镜轮(单色)或前置滤镜(OSC)。

**核心知识点**
- LRGB：L(亮通道,宽带,无色彩,提细节与信噪比)+ R/G/B(色信息)合成真彩；L 用单色相机拍最锐，RGB 可短曝光。
- 窄带三剑客：Hα（氢α，656.3nm）、O III（双电离氧，500.7nm）、S II（单电离硫，671.6nm）；发射星云在这些波长有强发射线。
- 窄带带宽：常见 3nm / 5nm / 7nm；带宽越窄抗光污染与隔离能力越强，但更贵、更慢(通光少)，一般 7nm 已够城市使用，3nm 用于极强光害或极致对比。
- 窄带抑光污染原理：城市灯光(钠灯约 589nm、汞灯 435/546nm 等)为宽泛连续谱；窄带滤镜通带仅几纳米，只放行星云发射线，几乎挡掉全部人工光与天光背景 → 信噪比大增。
- 配色映射：经典 SHO = SII(红)/Ha(绿)/OIII(蓝)的『哈勃色』；HOO = Ha(红)/OIII(绿蓝)；城市常用 Hα+OIII 双窄带。
- 双窄带(UV/IR cut + 双线)：如 L-eXtreme 在 OSC 前仅放行 Hα 与 OIII 两条带，一步曝光即得 nebula 伪彩，极大简化流程并压制光害。
- UV/IR cut：彩色相机(OSC)必须前置 UV/IR 截止，否则 Bayer 阵列外波段造成紫边/失焦；单色＋LRGB 时 L 滤镜本身含截止。
- 滤镜尺寸与传感器匹配：通光圆直径须 ≥ 传感器对角线；常见 1.25″(限于小传感器)、2″(≥31mm 传感器)、36mm 圆片、31mm 方；大传感器(如 2600 的 28.3mm 对角)必须用 2″/36mm 以上，否则暗角。

**注意事项**
- OSC 直接上单线窄带(Hα)几乎无色：OSC 需双窄带或配 L 才行；单色才适合单线轮替。
- 滤镜尺寸买小了：大传感器用 1.25″ 必黑角；先量传感器对角线再选尺寸。
- 窄带不能替代极轴/导星：它只管信噪比，不解决跟踪。
- 3nm 窄带配 f/7+ 慢镜会非常慢且可能波长偏移(大入射角导致中心波长漂移)，快镜(f/4–f/5)更友好。
- LRGB 中 L 与 RGB 需共焦(同焦点)，否则合成发虚；用巴洛/平场确认齐焦。
- 滤镜螺纹与相机/减焦镜前端口径一致(多数为 M48 2″)；注意后截距变化。

**示例**
- 单色入门窄带：Optolong L-eXtreme(7nm Hα+7nm OIII 双窄带，2″/36mm) 配 OSC 一步出图。
- 单色进阶：L(RGB)+ Ha(7nm)+ OIII(7nm)+ SII(7nm) 滤镜轮(36mm)，拍 SHO。
- 宽带真彩：LRGB 套装(各自带宽约 全可见，L 含 UV/IR cut)。

### 赤道仪选型 <a id="02-器材百科-赤道仪选型"></a>

> 难度：新手 ｜ 读者：准备搭建固定台址长曝光深空系统的新手与升级负载的进阶玩家 ｜ 标签：#器材 #赤道仪 #GEM #经纬仪 #极轴校准 #导星 #跟踪精度

**摘要**：深空长曝光必须用赤道仪(GEM)以抵消地球自转、避免视场旋转；经纬仪(Alt-Az)仅适合目视或短曝光/easy行星。选型核心看负载余量（实际成像负载控制在标称 50%–60% 以内）与导星下的跟踪精度（RMS 优于 1″ 为佳）。代表型号：信达 HEQ5 Pro / EQ6-R Pro、艾顿 iOptron CEM 系列、iOptron GEM28。

**适用场景 / 前置条件**：用于后院/野外的固定台址深空长曝光（单张数分钟、累计数小时）。若仅目视或拍行星/月亮短曝光，经纬仪更便捷；一旦要深空叠加，赤道仪不可或缺。

**核心知识点**
- 赤道仪(GEM)极轴对准天极后可单轴跟踪抵消自转；经纬仪(Alt-Az)两轴旋转会引入视场旋转，长曝光深空必须使用 GEM。
- 负载余量：标称负载(如 HEQ5≈13.7kg、EQ6-R≈20kg)为上限，深空导星建议实际『镜筒+相机+配重』总成像负载 ≤ 标称的 50%–60%，余量越大导星越稳。
- 跟踪精度指标：周期误差(Periodic Error, PE)常用峰峰值 peak-to-peak(如 ±5″–±10″)；导星后看 RMS（均方根），理想 ≤1″，优秀可达 0.3″–0.5″。
- PE 可通过 PEC（周期性误差校正）训练减小，但深空仍需导星(autoguiding)进一步压低残差。
- 极轴校准是精度前提：用极轴镜、iPolar 或 SharpCap 极轴辅助，偏差尽量 < 5′（对应场旋转可忽略）。
- GEM 中『中平衡(CEM)』结构（iOptron）重心更低、更省电、平衡更顺；传统 GEM 配重更直观。
- 步进电机 vs 伺服：现代 GEM 多用步进电机，安静、定位精度高；导星脉冲经 ST-4/脉冲导引接口控制。

**注意事项**
- 不要满载使用：长期接近标称上限会抖动、导星残差大、加速齿轮磨损。
- 忽略极轴校准直接导星：极轴歪会导致缓慢的场旋转/漂移，长时间叠加后星点拉线。
- 三脚架稳定性常被低估：轻薄脚架在风中会放大跟踪误差，优先重脚架+配重低挂。
- 经纬仪拍深空：除非有『赤道楔』或软件旋转，否则长曝光必然场旋转报废。
- 确认接口：赤道仪需有导星端口(ST-4/脉冲)、有足够 USB/电源走线空间。
- 寒冷环境电池/手控器续航下降，备好 12V 锂电池与保暖。

**示例**
- 入门 GEM：Sky-Watcher HEQ5 Pro（标称负载≈13.7kg，建议成像负载≤8kg，典型配 80–100mm 折射）。
- 进阶主力：Sky-Watcher EQ6-R Pro（标称负载 20kg，建议成像负载≤12kg，可带 8″ 牛顿/RC）。
- 中平衡之选：iOptron CEM70（标称≈31.8kg/70lb，建议≤18kg，省电低重心）。
- 轻量便携：iOptron GEM28（标称≈12.7kg/28lb） / CEM26（标称≈12kg），适合 80mm 级折射。
- 导星后精度参考：EQ6-R 经导星 RMS 约 0.5″–1″；HEQ5 约 0.7″–1.2″[不确定，随个体与校准而异]。

### 望远镜选型 <a id="02-器材百科-望远镜选型"></a>

> 难度：新手 ｜ 读者：深空天文摄影初学者与计划升级主镜的进阶玩家 ｜ 标签：#器材 #望远镜 #折射APO #牛顿反射 #RC #折反 #焦比

**摘要**：深空摄影主镜按结构分为折射APO、牛顿反射、RC与折反(SCT/Mak)四类；焦比(f/)决定集光速度与视场，口径决定分辨细节。新手首选折射APO（免维护、无色差），大视场星云选快焦比牛顿，小目标星系/行星状星云选长焦折反或RC。

**适用场景 / 前置条件**：已确定使用赤道仪与冷冻天文相机，需要为深空摄影（星系、星云、星团）挑选主镜。适用场景为后院/郊野固定台址的长曝光深空拍摄，而非目视或行星摄影。

**核心知识点**
- 焦比 f/ = 焦距 ÷ 口径；f/4–f/5 为『快镜』适合宽场星云，f/7–f/10 为『慢镜』放大倍率高、视场小、对导星与跟踪精度要求更高。
- 单位像素采样：像元视场 = 206.265 × 像素尺寸(μm) ÷ 焦距(mm) 角秒/像素；焦比越小、焦距越短，单像素覆盖天空越大（视场越宽）。
- 折射APO：三片式ED/萤石物镜，无色差、无需校准、密封免维护，但大口径价格高；典型 f/5.5–f/7。
- 牛顿反射（天文牛顿/Imaging Newtonian）：大口径低价格、集光力强，但需定期光轴校准(collimation)，且通常需平场镜纠正像场弯曲；典型 f/4。
- RC（里奇-克雷蒂安）：无球差、平场好、长焦比 f/8，适合小目标高放大；但 fn 长、对导星精度要求高，且需精确光轴校准。
- 折反 SCT/Mak：结构紧凑、便携、长焦比(f/10 左右)，适合行星状星云与星系；但视场小、受中心遮挡影响对比度，深空需加减焦镜提速。
- 中心遮挡：反射/折反类有副镜遮挡，会降低对比度；折射无遮挡，反差更干净。
- 经验法则：深空入门总预算中主镜约占总投入的 30%–40%，不要忽略赤道仪与导星的重要性。

**注意事项**
- 不要只看口径忽略焦比：大口径高焦比(f/10)的折反拍宽场星云极慢且不合适。
- 牛顿与RC必须重视光轴校准，未校准会严重星点变形、合焦困难。
- 确认后截距(back focus)与相机/滤镜轮的机械距离匹配，否则无法合焦或平场失败。
- 折射APO也有『像场平坦』问题，多数需加配平场镜/减焦平场镜(flattener/reducer)。
- Mak(马克苏托夫)焦比偏大(f/11+)，深空效率偏低，更适合行星/月面。
- 二手镜注意镜片镀膜划痕与反射镜氧化；APO注意是否有色差残留。

**示例**
- 折射APO 入门：Sky-Watcher Esprit 100ED（100mm，f/5.5，550mm） / 锐星（Sharpstar）94EDPH（94mm，f/5.5） / Askar 120APO（120mm，f/7，840mm 三片式）。
- 宽场星云：Sky-Watcher Quattro 200P 成像牛顿（205mm，f/4，800mm）需配平场镜与 coma corrector。
- 长焦小目标：GSO/信达 8寸 RC（203mm，f/8，约1624mm）；Celestron EdgeHD 8（203mm，f/10，2032mm，加 0.7x 减焦镜可到 f/7）。
- 便携折反：Celestron C8 SCT（203mm，f/10） / Sky-Watcher Skymax 127 Mak（127mm，f/11.8）。
- 配镜示例：ASI2600MC(3.76μm) + 100ED(f/5.5,550mm) → 采样≈1.41″/像素，适合 2–3″ 视宁度。

### 校准帧规范 <a id="03-拍摄sop-校准帧规范"></a>

> 难度：新手 ｜ 读者：准备做校准叠加(WBPP/DSS/Siril)以获得干净背景、去除热噪与暗角的深空拍摄者 ｜ 标签：#拍摄 #新手 #校准帧 #平场 #暗场 #偏置 #暗平场 #叠加

**摘要**：校准帧用于修正传感器与光路的系统误差：暗场(Dark)去热噪/偏置、平场(Flat)去暗角与灰尘阴影、偏置(Bias)去读出噪声、暗平场(Dark Flat)去平场里的噪声。核心铁律是「与亮场完全一致的曝光时间、增益/ISO、温度、光路与对焦」；平场 10–20 张、暗场 10–20、偏置 20–50、暗平场 10–20。换器材/转相机/改设置/积灰后必须重拍对应帧(尤其平场)。

**适用场景 / 前置条件**：适用：所有冷冻/非冷冻相机深空叠加。前置：已完成正常亮场拍摄计划。校准帧与亮场必须同相机、同增益、同温度(冷冻机尽量同设定值)、同焦平面位置；平场还需同对焦与同光学朝向。

**核心知识点**
- 平场(Flat)：修正暗角(vignetting)、灰尘阴影与不均匀照明。用均匀光源——白屏(T-shirt/白墙/专用白屏)、暮光天空(twilight，仅适合快速)、或 LED 平板/电动平场器(GIOTTO 等)。要点：与亮场同对焦、同增益/ISO；亮度调到 ADU 约落在传感器中间范围(既不饱和也不太暗，通常目标直方图中部偏上)；数量 10–20 张。
- 暗场(Dark)：测传感器热噪与偏置噪声。完全遮光(镜头盖/毯子盖镜筒防漏光)在总黑暗中拍摄；必须与亮场同曝光时间、同增益/ISO、同温度(冷冻机设同一目标温度)；数量 10–20 张。注意 DSLR/冷冻机白天可能有漏光，暗场须在黑夜全暗环境拍。
- 偏置(Bias)：测读出噪声与模式噪声，极短曝光。曝光设为最短(DSLR 约 1/4000s，冷冻机约 1/6400s)，镜头盖遮光，同增益/ISO；数量 20–50 张。用于校准暗场与平场里的偏置成分。
- 暗平场(Dark Flat)：与平场同曝光时间的暗场，去除平场里的暗电流/噪声，长曝光平场尤其重要。完全遮光、与平场同曝光/增益/温度；数量 10–20 张。
- 温度/增益一致性：暗场、偏置、暗平场对温度敏感，冷冻相机应固定同一制冷温度(如 -10°C)与增益；若当晚温度与库里暗场不同，应重拍。平场对增益/对焦/旋转敏感，须与亮场同设置。
- 数量经验：亮场 10–50(越多越好)；平场 10–20；暗场 10–20；偏置 20–50；暗平场 10–20。数量多可降随机噪声、提升 master 帧质量。
- 校准流程(软件自动)：合并偏置→主偏置；暗场减主偏置→主暗场；平场减主偏置或主暗平场→合并主平场；亮场减主暗场后除主平场；再对齐叠加。DSS 可全自动。
- 何时必须重拍：更换相机/滤镜/镜筒/减焦镜；旋转相机重新构图；清洁/积灰变化；改变 ISO/增益/曝光/对焦；制冷温度改变。运输拆装后建议至少重拍平场(相机朝向难完全复现)。

**注意事项**
- 平场亮度过饱和或太暗都会让平场失效，务必看直方图落在中段。
- 暗场/偏置漏光(USB 口、帘幕后漏光)会污染校准，须全黑遮光拍摄。
- 冷冻相机暗场温度与亮场不一致(如差几度)会引入残差热噪，应固定制冷温度。
- 清洁镜头后忘了重拍平场，旧灰尘阴影仍在，背景出现黑斑。
- 旋转相机重新构图却不重拍平场，暗角与灰尘位置变了，平场无效。
- 平场对焦必须与亮场一致(同一焦平面)，否则平场里的灰尘虚化、校正错误。
- 不要把白天顺手拍的「偏置」当暗场用——偏置极短曝光不含热噪。

**示例**
- 一晚标准校准集：平场 15–20 张(LED 平板，与亮场同增益同对焦)、暗场 15–20 张(同曝光同 -10°C 制冷，全遮光)、偏置 30 张(1/6400s 最短曝光)、暗平场 15 张(同平场曝光全遮光)。
- 暮光平场法：日落后天未全黑、天空均匀时，对天顶拍平场，注意亮度不过曝，迅速完成以避免天空梯度。
- 固定远程台可建立暗场/偏置库(同温同增益)，但平场每次构图中必须现拍。

### 对焦方法 <a id="03-拍摄sop-对焦方法"></a>

> 难度：新手 ｜ 读者：需要获得锐利星点、避免「虚焦」导致星点发胖或拉线的深空拍摄者 ｜ 标签：#拍摄 #新手 #对焦 #Bahtinov #FWHM #HFR #自动对焦 #NINA

**摘要**：对焦核心是把星点收到最小(衍射极限)。最适合新手的手动法是巴庭霍夫(Bahtinov)掩码：转动调焦环使中间衍射芒居于两侧芒正中即合焦；量化可用 FWHM/HFR。自动化则用 N.I.N.A 的 Star HFR 自动对焦(或 Hocus Focus 插件)，通过扫描调焦步长拟合曲线找最小 HFR 位置，配合温度/HFR 触发实现整晚自动再对焦。

**适用场景 / 前置条件**：适用：所有焦段。前置：望远镜已平衡、极轴大致完成、有亮星或目标可见。温度下降会使焦点漂移，故长曝光中途需复焦。注意 N.I.N.A 使用的是 HFR(半通量半径)而非 FWHM，二者都是「星点越小数值越小」的同义指标。

**核心知识点**
- 巴庭霍夫(Bahtinov)掩码：在镜口盖上带特定狭缝的掩码，亮星会产生 3 组衍射芒。合焦时中间那组芒正好位于左右两组芒的中间；任一方向离焦都会使中间芒偏移。转动电调焦/手动调焦环直到中间芒居中即完成。适合所有焦段，是最直观可靠的手动法。
- 亮星法/目视：在无掩码时，用预览循环曝光(如 2–3s)找一颗亮星，手动调焦到星点最小时径最小、拖线最短；依赖肉眼与拉伸，不如 Bahtinov 精确。
- FWHM / HFR 量化：FWHM(半高全宽)与 HFR(半通量半径)都衡量星点直径，数值越小越锐。N.I.N.A 自动对焦用 HFR：每帧检测星点并计算平均 HFR，拟合曲线找最小值。
- N.I.N.A Star HFR 自动对焦算法：从当前位置取基准 HFR → 向外移 Initial Offset Steps×Step Size → 以 Step Size 逐步向内测 HFR → 找到最小后拟合曲线移到最佳位置 → 校验(若最终 HFR 比初始差 ≥15% 则判定失败重试)。
- N.I.N.A 关键参数：自动对焦初始偏移步(Initial Offset Steps)Star HFR 默认 4、Contrast 默认 6；步长(Step Size)经验公式：从合焦向外移到星点不可检测的总步数 ×0.8 ÷ 初始偏移步(例：120 步不可检测→120×0.8÷4≈24–25 步)；曝光时间设到亮星接近饱和但多数星不溢出，并用 Annotate 确认能检测到足够星点；Contrast 法步长比 Star HFR 小 2–3 倍。
- Hocus Focus：N.I.N.A 的自动对焦插件/辅助工具，提供 HFR 曲线可视化与更灵活的调焦控制，可配合电调焦(EAF)使用。
- OSC 相机：N.I.N.A 中 Debayered HFR 保持开启以提高精度；在光污染下可调高 Star Sensitivity / Noise Reduction 以保证星点检测。
- 回差(Backlash)：在 AF 曲线上出现平段即回差，可设 Absolute 或 Overshoot 补偿，避免换向时焦点漂移。
- 整晚自动复焦：在序列中开启「温度变化时自动对焦」(温度变指定量触发)与「HFR 升高时自动对焦」(超过基线百分比触发)，由电调焦自动执行，无需人工。

**注意事项**
- Bahtinov 掩码必须口径匹配且居中，且对焦后「务必取下」再开拍，否则整晚黑图。
- 温度下降会令焦点前移，长曝光(尤其窄带/冬季)每隔数十分钟到一小时需复焦，否则星点逐渐发胖。
- 掩码衍射对离焦敏感但对合焦「不敏感」附近平台区，需细调找到正中而非大致居中。
- 电调焦回差未补偿会导致换向对焦失败或焦点跳动，需先测回差。
- 自动对焦曝光过长/过短都检测不到星点：过长饱和、过短信噪比差；以亮星接近饱和为准。
- Contrast 法峰更窄且偏实验性，新手优先用 Star HFR。

**示例**
- 手动合焦示例：对亮星盖 Bahtinov 掩码，循环 2s 曝光，调焦至中间衍射芒精确居中后取下掩码，再拍测试图确认。
- N.I.N.A Star HFR 自动对焦参数示例：Initial Offset Steps=4，Step Size≈25 步(由 120 步不可检测推算)，曝光令亮星近饱和，Debayered HFR=开，每点帧数 2–3，完成后校验失败阈值 15%。
- 整晚序列设置：开启 After temperature change=2°C 触发 AF，After HFR increase=10% 触发 AF。

### 导星 <a id="03-拍摄sop-导星"></a>

> 难度：进阶 ｜ 读者：已完成极轴与对焦、准备用 PHD2 做长曝光跟踪修正的进阶拍摄者 ｜ 标签：#拍摄 #进阶 #导星 #PHD2 #RMS #OAG #导星镜 #校准

**摘要**：导星用独立的导星相机持续监测一颗(或多颗)星，向赤道仪发送 RA/DEC 修正指令以消除周期误差、大气折射与残余极轴误差。PHD2 是事实标准：首次用设置向导→Calibration Assistant 校准→开启 Multi-star 与 Auto restore calibration。合格标准看总 RMS： backyard 常见seeing约 3"，RMS <1" 算好、<0.5" 优秀。导星方式上，短焦折射用导星镜即可，≥1500mm 长焦强烈建议 OAG。

**适用场景 / 前置条件**：适用：赤道仪+导星系统长曝光。前置：极轴已校准、导星相机已合焦、镜组平衡、设备已连接 PHD2(或经 N.I.N.A 联动)。导星只修正跟踪误差，不修正场旋转(那要靠极轴)也不修正星点虚焦。

**核心知识点**
- 原理：导星相机视场内监测星点位移，PHD2 计算后给赤道仪发脉冲修正；极轴准时主要只需 RA 方向修正，DEC 修正应保持很低。
- PHD2 设置流程：①读官方手册；②用 Setup Wizard 建立设备与 profile；③务必先把导星相机对好焦(星点不实会导致校准与导星失败)；④开启 Multi-star guiding(比单星更准)；⑤勾选 Auto restore calibration(不动设备时自动恢复上次校准，适合连拍多夜)；⑥用 Calibration Assistant 校准(会把镜筒指向子午线东/西几度的最佳位置，确保周边无遮挡)。
- 校准(Calibration)：PHD2 需要星点在各方向约移动 25 像素以得到准确校准矩阵；若校准失败常因选星太偏边或指向不当，重选中心附近亮星并重校。首次、换目标后、子午线翻转后都需重校。
- RMS 合格标准：PHD2 报告 RA、DEC 与各轴 RMS 及总 RMS(角秒)。backyard 平均 seeing 约 3"，总 RMS <1" 视为良好、<0.5" 优秀；RMS 应明显小于成像系统取样率(星点/像素对应的角秒/像素)，否则星点仍会拖。
- 导星参数：建议 RA 用 Predictive PEC 算法；min move(最小移动)与 backlash 补偿首次用 Guiding Assistant 测定(它会给出初始 min-move、回差补偿与导星曝光建议)；aggression(修正激进度)默认通常可用，过大会震荡、过小会跟不上。多数设置经 Guiding Assistant 自动获得即可。
- 导星曝光：以能稳定检测星点、噪声不过大为准；Multi-star 下可用较短曝光。导星镜焦距建议至少为主镜焦距的约 1/3(配合亚像素导星可放宽)。
- OAG vs 导星镜：导星镜易装、星多、可换镜，但存在 differential flexure(差挠曲)，长焦下精度不足且无法修正 SCT 镜筒下垂(mirror flop)；OAG 利用主镜同一光路、无挠曲、永不失焦、能修正 mirror flop，代价是安装复杂、极长焦时可能缺亮导星。经验：250–600mm 短焦折射用导星镜足够；接近 1000mm 用 OAG 更稳；≥1500mm OAG 几乎是唯一可行方案(如 RC/SCT/长焦牛反)。
- 与 N.I.N.A 联动：序列中 Start Guiding=On 时 N.I.N.A 命令 PHD2 选星并开始导星；dither(抖动)需导星已连接，在序列条目设 Dither Every # Frame 以打散热噪与坏点。

**注意事项**
- 导星相机没合焦就校准/导星必失败，白天可对远处目标粗合焦、夜里再细调。
- 导星镜装在 finder shoe 上易挠曲，应刚性固定(镜环+鸠尾)。
- RMS 高先查极轴而非猛调 aggression——极轴差是 DEC 高频修正的根因。
- Calibration Assistant 会让镜筒转动到子午线附近，务必确认周边无遮挡、三脚架不撞腿。
- 自动恢复校准(Auto restore)只在设备未移动时可靠；运输或翻转后必须重校。
- OAG 找不到导星时长焦窄带常见，可加亮星或换区/降 binning；不要因此硬上导星镜牺牲精度。

**示例**
- PHD2 推荐设置：Setup Wizard 建 profile → 导星相机合焦 → 勾 Multi-star guiding + Auto restore calibration → Calibration Assistant 校准 → RA 算法选 Predictive PEC → 首次跑 Guiding Assistant 求 min-move/回差/曝光。
- 导星镜选型示例：短焦折射(430mm)配 ZWO 30mm f/4 mini 导星镜 + ASI290MM Mini(小像素采样好)；长焦(RC 2000mm)改 OAG + 同品牌相机。
- 合格线参考：总 RMS 0.67" 为良好(例见 ASIAIR 导星)；目标 <1" 好、<0.5" 优秀；backyard seeing 约 3" 是天花板。

### 极轴校准 <a id="03-拍摄sop-极轴校准"></a>

> 难度：新手 ｜ 读者：使用赤道仪做长曝光深空拍摄、希望获得圆星点与低导星负担的爱好者 ｜ 标签：#拍摄 #新手 #极轴校准 #漂移法 #PoleMaster #SharpCap #跟踪

**摘要**：极轴校准是把赤道仪赤经轴对准天球北极(NCP/SCP)的过程，决定了跟踪是否平滑、是否存在「场旋转」(导星无法修正)。常用三法：漂移法(亚角分精度、gold standard)、电子极轴镜(QHY PoleMaster)、SharpCap 电子极轴(用导星相机+解析，精度可媲美 PoleMaster)。一般拍摄极轴误差在「几角分」内即可，长焦(800–2000mm)建议 1–2' 或更好，电子法常可做到 <1"。

**适用场景 / 前置条件**：适用：所有赤道仪长曝光。前置：已粗对极轴(大致指向北极星附近)、导星相机/极轴镜已装好、能看到北极星附近天空、控制软件(SharpCap/PHD2/ASIAIR/N.I.N.A)可用。极轴误差过大会在长焦下产生 DEC 拖线、四角蛋形星与频繁 DEC 修正。

**核心知识点**
- 精度要求（随焦距变化）：广角(14–50mm)允许「几角分」残余误差；中焦(200–600mm)建议「几角分内」；长焦(800–2000mm)建议约 1–2' 或更好；漂移法可达亚角分(sub-arcminute)精度。电子法(SharpCap/PoleMaster)常可做到总误差 <1"。
- 极轴不准的后果：产生场旋转(field rotation，导星无法消除)、DEC 漂移(赤纬方向拖线)、四角蛋形星、导星 DEC 修正频繁、长焦下星点拉长。导星可修正周期误差/大气折射但「不能替代」极轴校准。
- 漂移法步骤（gold standard，无需看到极点）：①选子午线附近、赤纬≈0°(天赤道)的星，跟踪下观察 2–3 分钟，星南北漂移=高度(altitude)误差，调赤道仪俯仰螺栓修正；②选东方或西方、地平高度约 20–30°、赤纬≈0°的星，观察 2–3 分钟，漂移=方位(azimuth)误差，调方位螺栓修正；③反复在两者间迭代，直到两处数分钟无明显漂移。需要带十字丝目镜或 PHD2 Drift Align、慢速微调螺栓与耐心(每次检查 2–4 分钟)。
- SharpCap 电子极轴(SharpCap Pro)：用导星相机+导星镜(约 200–300mm 焦距最佳)对北极附近拍两张图，RA 轴旋转约 90° 后软件解析并给出调整方向。要求：视场 1–2.5°、能看到 ≥15 颗星、已粗对极轴在 5° 内、相机被 SharpCap 支持。设置：高增益、曝光 4–8s 让星点足够；点 Tools→Polar Alignment，第一帧解析(solved)后 NEXT，解锁 RA 离合转 90°，再 NEXT 进入调整阶段，把指示星移到目标即可。可选开启折射修正(需设置经纬度)。精度可媲美 PoleMaster。
- 电子极轴镜 QHY PoleMaster：在极轴镜位置安装 PoleMaster 相机，软件识别极轴与 NCP 相对位置，按屏幕指示调 altitude/azimuth 螺栓，几步即可完成，适合无法方便用导星相机解析的场景。
- ASIAIR 极轴：在已对焦、输入正确焦距后点 PA，拍图后赤道仪 RA 转 45°，按屏幕角秒读数调 alt/az 螺栓，目标 <1" 总误差，显示笑脸即完成并回 home。
- 折射修正：低海拔/大纬度下大气折射会把视极点偏移约 0.5'(60°N/S)到 2'(25°N/S)，SharpCap 等可在设置中开启折射修正（位置精度 1° 内即可）。

**注意事项**
- 漂移法在调整阶段「不要」先动 altitude/azimuth，必须等软件进入最终调整阶段再调，否则破坏计算。
- SharpCap 极轴要求已粗对到极点 5° 内、视场 1–2.5°、≥15 颗星；用主镜长焦(如 714mm)解析太细难以微调，应改用导星镜(50–60mm)。
- 时区/经纬度设置错误会让 SharpCap 给出错误的上下左右调整方向。
- 极轴校准后若移动了设备(运输、碰撞、三脚架下沉)需重新校准；结露或风大时精度变差。
- 不要以为导星好就代表极轴准——导星会掩盖 DEC 漂移但场旋转仍在，长焦下四角星仍会变形。

**示例**
- SharpCap 极轴典型设置：导星镜焦距 200–225mm(如 50–60mm 导星镜)，导星相机高增益、曝光 4s，视场内 ≥15 星，旋转 RA 90° 后调整至 Polar Align Error 接近 0。(来源 AstroBackyard)
- 阈值参考：中焦 3–5 分钟单张要求极轴在「几角分」；长焦窄带长曝光要求 1–2' 或更好，苛刻项目用漂移法压到亚角分。(来源 Optical Mechanics)

### 拍摄序列计划 <a id="03-拍摄sop-拍摄序列计划"></a>

> 难度：进阶 ｜ 读者：希望用 N.I.N.A 做一夜自动化拍摄(多目标/多滤镜/LRGB/窄带)、减少现场值守的进阶用户 ｜ 标签：#拍摄 #进阶 #序列 #NINA #多目标 #多滤镜 #自动平场 #子午线翻转

**摘要**：N.I.N.A 序列把「冷却相机、解锁/停泊赤道仪、解析居中、旋转、起导星、按滤镜拍 N 张、抖动、自动复焦、子午线翻转」编排成可无人值守运行的计划。多个目标可开多个序列标签页按序先后运行；多滤镜(如 LRGB/SHO)在一个目标内分行设置不同滤镜与曝光；自动平场可在晨昏触发。关键开关：Start Guiding、Auto Meridian Flip、After temperature/HFR 自动对焦、Dither。

**适用场景 / 前置条件**：适用：N.I.N.A 用户(冷冻/非冷冻相机、GOTO 赤道仪、电调焦、滤镜轮、导星)。前置：设备已连接并连接 PHD2、已极轴与对焦、已建好目标坐标(可经 Stellarium/SkySafari 或解析导入)。

**核心知识点**
- 多目标：N.I.N.A 可开多个序列标签页，各目标独立设置；前一目标完成后自动运行下一个，实现一夜多目标。可用 Prioritize/Deprioritize 调整先后。可在 Options>Imaging>Sequence 指定模板自动载入新标签。
- 序列集选项(整套目标共用)：开启 Cool Camera 与 Unpark Mount 会在「第一个」目标前执行；Warm Camera 与 Park Mount 在「最后一个」目标后执行；可开启 Auto Meridian Flip(子午线翻转)对整个序列生效。
- 目标起点选项：Slew to target(按 RA/Dec 指向，不验证) / Center target(用解析 plate solve 把目标居中) / Rotate target(接 rotator 旋转到指定角度) / Start Guiding(序列开始命令 PHD2 选星起导星，注意序列开头会先停导星，仅当此选项开才重启)。
- 自动对焦行为：可设 After temperature change(温度变化指定量触发 AF，温度取自电调焦；调焦器无温度则暂不支持天气源)与 After HFR increase(上一拍 HFR 比基线高指定百分比触发 AF，基线取自 AF 后首帧)。配合电调焦实现整晚无人复焦。
- 序列条目(每行=一种曝光)：含 Total #(张数)、Time(秒)、Type(LIGHT/FLAT/DARK/BIAS)、Filter、Binning、Dither(开)、Dither Every # Frame(每 N 张抖一次)、Gain、Offset。Dither 仅在导星已连接时有效，利用下载间隙执行，可打散热噪。
- 序列模式：One after another(逐条完整拍完再进下条) / Loop(每条各拍一张后循环直到全部完成)，适合多滤镜轮拍。
- Build Sequence：可把简单序列一键送往 Advanced Sequencer 做更细粒度编排(触发器/条件/多设备)，但注意会覆盖高级序列里已有内容。
- Session/露营(camping)：用 Advanced Sequencer 配合 Triggers(触发条件)实现复杂逻辑，如「天空亮度降到阈值自动开始」「晨昏触发自动平场」「特定时间/高度开始/结束目标」「温度/湿度触发收工」。
- 自动平场(Auto Flats / Dawn Flats)：可安排在暮光或晨光、或用平场光源，设目标 ADU/亮度触发，N.I.N.A 自动拍够平场数量；适合固定台与懒人流程。
- 完成时间预估：N.I.N.A 按张数×曝光+下载时间给出 Estimated Finish Time，便于安排一夜计划。

**注意事项**
- Start Guiding 未开则序列不会自动起导星，首帧就可能拖线；序列开头会先停导星，需此开关才重启。
- 多滤镜单色机务必设好滤镜偏移(filter offsets)，否则换滤镜后焦点漂移、星点虚。
- Center target 依赖解析(plate solve)可用与坐标准确，坐标错会指向空区。
- Dither 不开则热噪/坏点会固定叠加成条纹，务必开且接好导星。
- Build Sequence 会覆盖 Advanced Sequencer 已有内容，改高级序列后别随手再点。
- 自动平场触发条件(亮度/时间)设错会在不合适时机乱拍，固定台建议先手动验证。
- 长目标跨子午线务必确认 Auto Meridian Flip 开启且翻转后重新解析/居中，否则翻转后脱靶。

**示例**
- 单目标 LRGB 序列：目标 M51，Center+Start Guiding+Auto Meridian Flip 开；条目 L 30×180s、R 20×180s、G 20×180s、B 20×180s，Dither Every 3，After temperature 2°C 触发 AF。
- 一夜多目标：开 3 个序列标签(NGC7000→M31→M33)，各设自身坐标/滤镜/曝光，N.I.N.A 依次自动运行；整套 Cool/Unpark 在前、Warm/Park 在后。
- 窄带 SHO 自动流程：Advanced Sequencer + Trigger，夜幕亮度阈值启动 Ha/SII/OIII 各若干张，晨光触发自动平场，温度降触发收工 Warm/Park。

### 现场搭建流程 <a id="03-拍摄sop-现场搭建流程"></a>

> 难度：新手 ｜ 读者：刚入手赤道仪+望远镜+冷冻相机/导星系统的深空拍摄新手，以及需要标准化出队流程的团队 ｜ 标签：#拍摄 #新手 #现场搭建 #赤道仪 #平衡 #检查清单

**摘要**：从抵达场地到按下第一张曝光，应按「选址供电→三脚架水平→赤道仪装机供电→镜组与平场镜安装→RA/DEC 平衡→相机/滤镜/导星连接→APP初始化→粗对焦→极轴校准→目标解析对焦→导星校准→序列开拍」的固定顺序操作。把平衡、55mm 后截距、线材整理和供电余量当成硬指标，可避免 80% 的现场故障。

**适用场景 / 前置条件**：适用场景：夜间户外（ backyard 或暗场）架设德式赤道仪(GEM)进行长曝光深空拍摄。前置条件：已具备赤道仪、望远镜(含平场镜/减焦镜)、冷冻主相机、导星镜/导星相机或 OAG、供电(12V 锂电池或市电)、控制终端(笔记本/N.I.N.A 或 ASIAIR)。

**核心知识点**
- 选址与供电：选平坦干燥、不塌陷（草地需垫板）、有 12V 供电或充足锂电池、且能看见北天极(NCP)的方向无遮挡的机位。
- 三脚架：置于水平地面，用自带气泡水平仪调至「尽量水平」；重载脚架不依赖中轴承重。
- 赤道仪装机与供电：装上赤道仪头，用原厂 12V 电源（如 EQ6-R 约 12V/5A）独立供电，不建议由控制盒(ASIAIR)反向取电给赤道仪。
- 镜组安装：望远镜经 Vixen/Losmandy 鸠尾板装到赤道仪，加装平场镜/减焦镜；导星镜(或 OAG)装在镜筒上方鞍座，用镜环+鸠尾条保证刚性，避免导星镜在寻星鞋上松动产生挠曲。
- 平衡（关键）：先松开赤经(RA)离合，让镜筒转到镜身一侧居中、加减配重使 RA 轴两侧平衡；再松开赤纬(DEC)离合，让镜筒水平、调镜筒在抱箍中的位置使 DEC 轴平衡。平衡不良会导致跟踪抖动与导星负担加重。
- 相机与光路：主相机经滤镜抽屉/滤镜轮接到镜尾，务必满足后截距（ZWO ASI 常见 55mm 传感器到焦平面距离），否则星点边缘不实。
- 导星连接：导星相机接导星镜/OAG；导星相机 USB 可接主相机或控制终端，并接好防露加热带。
- 线材整理：用魔术贴/绑带把 USB、电源线沿镜筒固定，避免线缆重量拉扯造成挠曲或意外扯断；使用带供电的 USB 集线器。
- 控制终端初始化：连上设备后输入站点经纬度、主镜焦距(如 430mm)、导星镜焦距(如 200mm)，设置相机增益（如 ASI533 用 Gain 100）、开启防露。
- 粗对焦与测试图：取下强滤镜，用预览/对焦模式循环 2–3s 曝光，手动调焦至星点收紧，拍一张测试图确认光路与构图。
- 极轴校准→目标解析→精细对焦→导星校准→序列开拍：见对应知识点（polar/focus/guiding/sequence）。

**注意事项**
- 不要把赤道仪电源接到 ASIAIR 等控制盒上反向取电，可能导致电压不足、跟踪异常。
- 导星镜装在 finder shoe（寻星镜座）上极易产生 differential flexure（差挠曲），应用镜环+鸠尾板刚性固定。
- 后截距不对（如未达 55mm）会导致平场镜后星点不实，应在白天就确认接环厚度。
- 三脚架架在草地上会随夜露/承重下沉，造成极轴漂移，应垫板或选硬地。
- 平衡只做 RA 不做 DEC，或配重过紧，都会导致导星 RMS 偏高与周期误差放大。
- 线缆未固定，风大或被绊时会瞬间拉偏指向，务必绑扎。
- 忘记开防露加热带，镜口结露会让整晚报废。

**示例**
- 典型折射 430mm  setup：EQ6-R Pro + WO Zenithstar 73 + WO 50mm 导星镜 + ASI533MC Pro(Gain100) + ASI120MM Mini 导星 + ASIAIR Plus；后截距 55mm，导星镜焦距 200mm。
- 出队检查清单顺序：场地/供电→三脚架水平→赤道仪装机+独立 12V 供电→镜组+平场镜+导星镜→RA/DEC 平衡→相机+滤镜+导星连接→线材绑扎+防露→终端初始化(坐标/焦距/增益)→粗对焦测试图→极轴→解析目标→精细对焦→导星校准→序列。

## 04-后期处理

### LRGB处理与调色 <a id="04-后期处理-lrgb处理与调色"></a>

> 难度：进阶 ｜ 读者：已掌握叠加、想要做宽带彩色（星系/星云）并正确合成亮度与色彩通道的拍摄者。 ｜ 标签：#后期 #进阶 #LRGB #调色 #PixInsight #SCNR #拉伸

**摘要**：LRGB 把高分辨的 L（亮度）通道与 R/G/B 彩色通道合成，兼顾细节与色彩。PixInsight 中流程为：线性阶段做色彩校准（ColorCalibration / PhotometricColorCalibration）、各通道 LinearFit 对齐背景；非线性后用 LRGBCombination 合成、SCNR 去绿、曲线拉伸与局部增强。关键在于先校准色彩再拉伸，并把 L 的细节「借」给彩色图。

**适用场景 / 前置条件**：需要：已分别叠加好的 L、R、G、B 主图（也可用合成亮度 Synthetic Luminance 代替真实 L）。软件：PixInsight（LRGBCombination、ColorCalibration、SCNR、CurveTransformation、HistogramTransformation、ChannelCombination、LinearFit）。若素材为 OSC 单色相机，可用 ChannelExtraction 抽取合成 L。

**核心知识点**
- 色彩校准（线性阶段）：用 ColorCalibration 或 PhotometricColorCalibration（基于 Gaia 星表，Spectrophotometric 模式）做初始白平衡，消除滤镜/大气带来的色偏。
- 通道亮度对齐：用 LinearFit 把 R/G/B 的背景与强度统一到同一参考通道，避免某通道过强导致偏色。
- 合成亮度 L：优先使用真实 L 通道（可透过光害滤镜拍更长曝光获得更多信号）；无 L 时用 ChannelExtraction 抽取 R/G/B 合成 Synthetic Luminance。
- LRGBCombination（非线性阶段）：将 L 的亮度信息赋予彩色图。典型做法——先拉伸 L 与 RGB，再把 L 作为 Luminance、RGB 作为 Chrominance 合成；可用 Luminance 滑块控制 L 贡献（常 0.7–1.0），并可对彩色图做轻微降噪（Chrominance 降噪）。
- SCNR（Subtractive Chromatic Noise Reduction，去绿）：Ha 发射星云常导致绿色溢出，用 SCNR 选 Green、Method=Average Neutral 把绿色中和；若想保留哈勃 palette 的绿则跳过。
- 曲线拉伸：线性阶段用 ScreenTransferFunction（STF）仅用于预览；正式拉伸用 HistogramTransformation（拖动中灰/黑点）或 CurveTransformation（Arcsinh/自定义曲线）把暗部提亮，避免一次性过曝。
- 通道对齐/色度噪声：合成后若仍有色噪，用 ACDNR（Chrominance 模式）针对颜色噪声做最终降噪；星点可用 StarNet/StarXTerminator 分离后再分别处理。
- 局部增强：用 CurvesTransformation + 星点/结构蒙版（Star Mask / Range Mask）提升星云细节与对比，避免整体提亮导致背景发灰。

**注意事项**
- 务必先在线性阶段完成色彩校准与 LinearFit，再拉伸；先拉伸后校准会导致色偏难以修正。
- LRGBCombination 前 L 与 RGB 需都已拉伸到相近显示范围，否则合成后细节错位或偏色。
- 不要过度 SCNR，会把本该有的绿色（如 Ha 区域）全部抹掉，丢失科学信息。
- 拉伸（STF）只是预览，不会写入像素；正式出图必须用 HistogramTransformation/CurveTransformation。
- L 通道与 RGB 的配准/采样必须一致（建议同像素尺度），否则合成后星点重影。
- OSC 相机直接出彩色帧时无需 LRGBCombination 合成，但仍需做色彩校准与拉伸。

**示例**
- PixInsight LRGB 流程：叠加 L/R/G/B → 线性阶段 ColorCalibration + 各通道 LinearFit → BlurXTerminator/NoiseXTerminator 降噪与反卷积 → 拉伸 L 与 RGB（CurveTransformation）→ LRGBCombination（L 为亮度、RGB 为色度）→ 视情况 SCNR Green → 局部 Curves 增强 → ACDNR 收色噪。
- 无真实 L：ChannelExtraction 从 RGB 抽 L，再用 LuminanceWorkflow 提升对比后并入彩色图。
- Ha 强星云去绿：Process > SCNR，Parameters 选 Green、Method=Average Neutral、Amount 通常 0.7–1.0，配合星点蒙版避免影响星色。

### Photoshop精修 <a id="04-后期处理-photoshop精修"></a>

> 难度：进阶 ｜ 读者：已在 PixInsight/Siril 完成主流程、需要进入 Photoshop（或 Affinity Photo）做最终拉伸、降噪、星点管理与局部润色的用户。 ｜ 标签：#后期 #进阶 #Photoshop #降噪 #星点 #局部增强 #NoiseXTerminator

**摘要**：Photoshop 是窄带/宽带主图完成后的精修终端：用 16-bit 模式与曲线/色阶做最终拉伸，配合 RC Astro 的 NoiseXTerminator（AI 降噪）、StarXTerminator（星点分离）与 StarShrink（星点缩小）管理星点，再用蒙版做局部亮度/色彩增强。关键是用蒙版保护背景与星点，分层非破坏式编辑。

**适用场景 / 前置条件**：需要：已拉伸、可视觉化的主图（从 PixInsight 导出 16-bit TIFF，建议保留 LAB/RGB）。软件：Photoshop CC 或 Affinity Photo 2；RC Astro Photoshop Bundle（NoiseXTerminator、StarXTerminator、GradientXTerminator、StarShrink，付费，许可证也可用于 PixInsight/CLI）。

**核心知识点**
- 导入与位深：用 16-bit/channel 模式打开 TIFF，所有调整层（Curve/Levels/HP 滤镜）非破坏式操作，便于回退。
- 最终拉伸：用 Curves（曲线）或 Levels（色阶）做非线性拉伸；对星云暗部用 S 形曲线提对比，配合图层蒙版只作用于目标区域。
- AI 降噪 NoiseXTerminator（RC Astro，Photoshop 滤镜）：ML 降噪，保留暗弱结构与星点形状；参数 Strength 控制强度，通常在背景/暗部强、结构区弱（可加蒙版分区）。
- 星点分离 StarXTerminator：把星点与星云/星系分离为两个图层，便于分别对星点调色缩星、对星云单独提细节而不影响星点。
- 星点缩小 StarShrink：智能收紧过曝/膨胀的大星点（受大气与曝光影响），不伤周围结构，让深空目标更突出。
- 梯度校正 GradientXTerminator：消除光害/暗角/月光造成的大尺度渐变背景（也可在 PixInsight 的 DynamicBackgroundExtraction 先做）。
- 局部增强：用 Luminosity 蒙版（或自绘选区）对星云核心/暗云做 Curves 提亮或对比增强；用 Selective Color / Hue-Saturation 微调色相。
- 星点着色：分离后的星点层可整体调色（如中性灰偏暖），避免紫边；用蒙版防止背景被污染。
- 导出：最终存为 16-bit TIFF 母版，网络发布再转 8-bit sRGB JPEG/PNG，注意色彩空间转换。

**注意事项**
- 不要用 8-bit 流程精修，会断阶（banding）；始终 16-bit 以上。
- NoiseXTerminator 强度过高会抹掉暗弱星云细节，建议分区域蒙版、适度。
- StarXTerminator 分离后若直接删除星点层会丢失星点，需保留或重新合成。
- Photoshop 中星点缩小过度会让画面显得「假」、失去星野氛围，适度即可。
- 不要在未对齐的图层上做局部增强，避免错位。
- 导出发布版务必先把 ProPhoto/AdobeRGB 转 sRGB，否则网页显示偏色。[不确定：部分工作流保留更广色域母版]

**示例**
- PS 精修流程：PixInsight 导出 16-bit TIFF → PS 用 Curves 做最终 S 形拉伸 → 副本层跑 NoiseXTerminator（Strength 中值）→ StarXTerminator 分离星点 → 对星云层做 Luminosity 蒙版局部增强 → StarShrink 收星点并调星色 → 合并 → 导出。
- 梯度处理：先在 PixInsight 用 DynamicBackgroundExtraction 去梯度，残留渐变再到 PS 用 GradientXTerminator 收尾。
- 局部增强示例：新建 Curves 调整层，用画笔在星云暗部蒙版内提亮、在背景区压暗，营造立体感。

### 窄带SHO映射 <a id="04-后期处理-窄带sho映射"></a>

> 难度：高手 ｜ 读者：使用 Ha/SII/OIII 窄带滤镜拍摄星云，希望把单色信号映射成科学/艺术化彩色（哈勃调色板）或把窄带融入宽带的进阶用户。 ｜ 标签：#后期 #高手 #窄带 #SHO #HaRGB #PixelMath #哈勃调色板 #PixInsight

**摘要**：窄带映射是把 Ha、SII、OIII 三个单色通道按规则分配到 R/G/B，最经典是 SHO（SII→红、Ha→绿、OIII→蓝）即哈勃调色板。PixInsight 可用 ChannelCombination 做静态映射，或用 PixelMath 写表达式做「动态映射」（每个像素比例不同）以获得更丰富的色彩。HaRGB 则是把 Ha 当作亮度/细节并入彩色 RGB 图。

**适用场景 / 前置条件**：需要：分别叠加好的 Ha、SII、OIII 单色主图（建议已配准、背景值对齐）。软件：PixInsight（ChannelCombination、PixelMath、CurveTransformation、LRGBCombination）；也可用 Siril 的 PixelMath 公式。HaRGB 还需 RGB 或 L 通道。

**核心知识点**
- 标准哈勃调色板（SHO）映射：SII→Red、Ha→Green、OIII→Blue。用 ChannelCombination（Combine 模式，分别指定 R=SII、G=Ha、B=OIII）即可完成静态映射。
- 替代调色板：HOO（Ha→红、OIII→蓝、绿常取 Ha 与 OIII 混合）、HSO 等可自由分配；窄带数据不必拘泥于 SII=红。
- 静态（static）映射：各通道系数为固定数字，且系数之和须=1 以避免通道截断（如 R=.6*SII+.4*Ha）。
- 动态（dynamic）映射（PixelMath）：系数不是常数而是随像素变化的「图像」。例：以 f = (OIII*Ha) 的拉伸副本作为动态因子，使 Ha/OIII 都强的区域偏向某色、弱区保持 HOO，色彩更自然。
- 通用 PixelMath 表达式（The Coldest Nights，Sii/Ha/Oiii）：R = (Oiii^~Oiii)*Sii + ~(Oiii^~Oiii)*Ha；G = ((Oiii*Ha)^~(Oiii*Ha))*Ha + ~((Oiii*Ha)^~(Oiii*Ha))*Oiii；B = Oiii。（~X 表示 1-X 反相；系数和=1）
- Ha/Oiii 双窄带通用式：R = Ha；G = ((Oiii*Ha)^~(Oiii*Ha))*Ha + ~((Oiii*Ha)^~(Oiii*Ha))*Oiii；B = Oiii。
- 混合前准备：动态映射要求各窄带通道已拉伸且背景值近似一致；否则先用 CurvesTransformation 调整。
- HaRGB（窄带+宽带）：把 Ha 作为亮度/细节层用 LRGBCombination 并入 RGB 彩色图（Ha 作 L 或额外细节），突出恒星形成区；星系常加 Ha 强调 HII 区。
- 亮度层与调色：SHO 合成后建议另建 Luminance 层（如用 Ha 或 Ha+OIII）提升质感；再用 CurvesTransformation 的 Hue 微调星点颜色（紫色星点可对星蒙版做 SCNR Green 再反相）。

**注意事项**
- PixelMath 表达式中各通道系数之和必须等于 1，否则会截断/溢出（PixelMath 输出归一化到 [0,1]）。
- 动态映射依赖拉伸后的数据；线性阶段直接做动态映射需改用拉伸副本，否则因子无意义。
- 各窄带通道背景值差异过大会导致映射后偏色，需先对齐背景（LinearFit / 背景归一化）。
- 双窄带（如 Ha+OIII duo-band）缺少真实 SII 时，只能用 PixelMath 合成「模拟硫」通道，非真实 SHO。
- 不要过度追求哈勃金蓝配色而牺牲科学真实性，必要时保留说明。
- 星点颜色异常（偏紫）通常是通道配准或缩放不一致所致，先检查对齐再调色。

**示例**
- 静态 SHO（PixInsight）：Process > ChannelCombination，Combine，R 选 SII、G 选 Ha、B 选 OIII → 应用。
- 动态 SHO（PixelMath）：R = (Oiii^~Oiii)*Sii + ~(Oiii^~Oiii)*Ha；G = ((Oiii*Ha)^~(Oiii*Ha))*Ha + ~((Oiii*Ha)^~(Oiii*Ha))*Oiii；B = Oiii。
- HaRGB：先把 RGB 彩色图做好，再用 LRGBCombination 把 Ha 作为 Luminance 并入，增强发射区细节。
- Siril PixelMath 模拟：Red=0.8*R+0.2*B、Green=R、Blue=0.5*B+0.5*G（依素材调比例，再进 Photoshop 微调）。

### 校准与叠加 <a id="04-后期处理-校准与叠加"></a>

> 难度：新手 ｜ 读者：所有深空拍摄者（新手到进阶），需要把一夜到多夜采集的亮场合成一张高信噪比主图。 ｜ 标签：#后期 #叠加 #校准 #WBPP #DSS #Siril #PixInsight

**摘要**：叠加（Stacking/Integration）是把多张亮场通过校准（暗场/平场/偏置）与配准后做像素级平均，从而大幅提升信噪比的核心步骤。PixInsight 的 WBPP 脚本可一站式完成校准、配准、加权、坏帧拒绝与叠加；DSS 与 Siril 是免费的轻量/开源替代。现代 CMOS 相机暗场基本可省略，关键是平场与合理的像素拒绝算法（Winsorized Sigma / GESD）。

**适用场景 / 前置条件**：需要：单张或多夜拍摄的亮场（Lights），以及校准帧（暗场 Darks、平场 Flats、偏置 Bias，现代 CMOS 常用 Flats+Bias，暗场多可省略）。软件任选其一：PixInsight（WBPP 脚本，付费）、DeepSkyStacker（Windows 免费）、Siril（跨平台开源免费）。叠加前建议先用 Blink 工具目视检查并剔除卫星/飞机划痕等坏帧。

**核心知识点**
- 校准帧作用：Bias 去除读出电子噪声；Darks 去除热噪声与 amp glow（现代 CMOS 暗电流极低，常可省略）；Flats 校正暗角与灰尘。WBPP 默认流程为 Master Bias → 校准 Master Flat → 校准 Lights。
- PixInsight WBPP（Script > Batch Processing > WeightedBatchPreprocessing）：一次导入 Lights/Darks/Flats/Bias，自动完成 Calibration → Registration → Frame Rejection → Weighting → Integration → Drizzle → Auto Crop。
- WBPP 加权：默认 PSF Signal Weight（按星点 FWHM 锐度加权），优先使用更清晰的帧，降低手动挑帧需求。
- 像素拒绝（Integration Parameters > Pixel Rejection）：默认 Auto，建议改为 Winsorized Sigma Clipping（帧数少、有飞机/卫星划痕时更稳）或 Generalized Extreme Studentized Deviate (GESD)（帧干净时更优）。
- Exposure Tolerance（Post-Calibration 下）：设为 300 可将 300s 与 600s 等不同曝光长度的亮场合为一组；否则 WBPP 会按曝光长度拆成多组。
- Drizzle Integration（DrizzleIntegration 模块）：利用亚像素精度提升有效分辨率，建议至少 30 张以上亮场再做，否则收益有限。
- 坏帧处理：叠加前用 Blink 逐帧查看，删除明显卫星/飞机轨迹、严重拖线、失焦帧；也可在 WBPP 的 Calibration 标签页用 Show Calibration Diagram 核对各滤镜是否正确匹配对应平场（避免 OIII 平场去校准 Ha 亮场）。

**注意事项**
- 不要混用不同曝光长度而不设 Exposure Tolerance，否则会被拆成多张叠加图。
- 过滤器（Filter）命名必须正确，否则 WBPP 会用错平场校准亮场，导致梯度/暗角。
- 现代 CMOS 不必强求暗场；若做了暗场，注意温度/曝光需与亮场一致。
- Drizzle 会放大分辨率但可能放大噪点/降低信噪比，帧数不足（<30）时不建议。
- 叠加量并非越多越好：SNR 提升遵循 √N 规律（叠加 N 张噪声降为 1/√N），到一定时长后边际收益递减；典型总曝光 4–10 小时，单项目 20–200 帧皆常见。
- 总曝光不足时用激进拒绝算法会损失信号，帧数少时优先 Winsorized Sigma Clipping。

**示例**
- 推荐流程（PixInsight WBPP）：导入 Lights（带滤镜名）+ Flats（每滤镜）+ Bias → 默认 PSF 加权 → Pixel Rejection 改 Winsorized Sigma Clipping → Exposure Tolerance=300（多曝光时长时）→ 运行 → 得到校准并叠加的主图。
- 免费方案（Siril）：各滤镜分别执行 预处理（Pre-processing，自动调用 darks/flats/bias）→ 配准（Registration）→ 叠加（Stacking，默认 Winsorized Sigma Clipping）。
- 免费方案（DSS）：添加亮场 → 自动识别/添加校准帧 → 默认叠加，适合 Windows 新手快速出图。
- 叠加量示例：60 × 3 分钟 = 3 小时；进一步提升靠增加总曝光而非单张时长。15 张叠加的 SNR 已明显优于单张。

## 05-目标图鉴

### 经典目标推荐参数 <a id="05-目标图鉴-经典目标推荐参数"></a>

> 难度：新手 ｜ 读者：深空天文拍摄新手与进阶爱好者，想要快速套用经过验证的器材与曝光参数来拍摄经典目标的人群 ｜ 标签：#目标图鉴 #参数 #曝光 #滤镜 #焦距 #积分时间

**摘要**：本文给出 5 个经典目标（M42 猎户座大星云、M31 仙女座星系、M51 涡状星系、M81 波德星系、NGC7000 北美洲星云）的推荐焦距、单张曝光、滤镜与建议总积分时间。亮星云/发射星云（M42、NGC7000）用广角+窄带即可快速出片；星系（M51、M81、M31）需要中长焦与较长积分，M42 还需长/短曝光 HDR 以防核心过曝。

**适用场景 / 前置条件**：参数来自 AstroBackyard 等教程的真实拍摄案例，适用于赤道仪+制冷天文相机或改机/普通单反。具体数值会随器材（像素、光圈、光污染等级）变动，下表为经过验证的起步参考值，可据本地条件微调。

**核心知识点**
- M42 猎户座大星云（冬季，亮弥漫星云）：推荐焦距 400–600mm（可同框奔跑者星云 NGC1977）；APO 折射镜或准直牛反最佳。单帧：导星赤道仪下 60 秒以上，单反 2–3 分钟（ISO 800–1600）；DSLR 手动 B 门。总积分：0.5–10 小时皆可出片。滤镜：新手可用宽带光污染滤镜（如 Optolong L-Pro），进阶用 LRGB 或叠加 Hα。关键：明亮核心在 15 秒左右即可能过曝，建议拍「短曝光（5–15 秒）+长曝光」两组后期 HDR 融合。
- M31 仙女座星系（秋季，超大亮星系，约 190′×60′）：推荐焦距 250–480mm（RedCat 51 @250mm 或 ED80 @480mm 完美构图；135mm 镜头可带更大周围空间）；焦距过长需 mosaic。单帧：1.5–4 分钟，ISO 800–1600（新手目标 30×3 分钟=1.5 小时）。总积分：约 1.5–3.5 小时已可出片（实战案例 100×1.5min≈2.5h、51×4min=3h24m）。滤镜：轻度光污染滤镜（IDAS LPS D1 / SkyTech CLS-CCD）即可，城市短曝光只见核心需后期蒙版拉细节。
- M51 涡状星系（春季，面朝上旋星系，约 11′×7′，高面亮度）：推荐焦距 800–1050mm（Sky-Watcher Esprit 150 @1050mm F/7；老案例 8″ F/4 牛反 @800mm）。单帧：300 秒（5 分钟）最常见。总积分：约 6 小时（实战：36×300s Lum + 9×300s R + 12×300s G + 15×300s B = 6h，单色 LRGB）。滤镜：宽带 LRGB（彩色相机可免滤镜）；城市可用 L-Pro 等。M51 表面亮度高、旋臂细节好，是中长焦星系入门首选。
- M81 波德星系（春季，约 27′×14′，亮星系，常与 M82 同框）：推荐焦距 800–2000mm（实战 EdgeHD 11 + 0.7× 减焦 @约 1985mm 拍特写；中焦 800–1000mm 可把 M81+M82 同框）。单帧：180 秒（3 分钟）。总积分：约 4 小时（实战 80×3min，Bortle 7  backyard，未用光污染滤镜）。滤镜：亮星系在 Bortle 7–8 也可拍，可不用滤镜或轻度光污染滤镜；后期处理渐变与天光。最佳窗口 2–5 月。
- NGC7000 北美洲星云（夏季，超大发射星云，约 120′×100′）：推荐焦距 100–400mm（Rokinon/Samyang 135mm F/2 最常见，可同框鹈鹕 IC5070；RedCat51/ED80/Askar SQA55 等广角折射）。单帧：4–5 分钟，ISO 800–1600（实战 ED80 35×5min≈2h55m、RedCat51 53×4min≈3h32m）。总积分：约 3 小时已出片。滤镜：Ha 窄带或双窄带（Hα+OIII，如 Optolong L-eNhance、Astronomik 12nm Ha 夹式）效果最佳，亮至可在无改机单反下直接拍；配合星野 tracker（如 iOptron SkyGuider Pro）即可入门。

**注意事项**
- M42 核心极亮，必须做长短曝光 HDR，否则核心全白无细节；单帧 >15 秒即可能过曝。
- 星系（M31/M51/M81/M101）面亮度低，单帧 3–5 分钟、总积分 4–6 小时以上信号更佳；光污染重时优先窄带或去光害滤镜，并尽量选暗空/新月。
- NGC7000 与 M31 体积巨大，焦距过长会装不下，务必先用 FOV 计算器确认构图（参考 astronomy.tools FOV 计算器）。
- 单反/微单 ISO 建议 800–1600，制冷天文相机（OSC/单色）按增益与温度设定，单帧可更长（5 分钟）。
- 所有积分时间为参考下限，城市（Bortle 6–8）应酌情增加 30%–100% 以压制噪点与天光。
- 参数随相机像素、光圈、滤镜透过率变化；本文数值为已验证起点，需结合本地实测微调[不确定，具体总积分因器材而异]。

**示例**
- M42 入门实战：APO 折射镜 480mm + 彩色制冷相机，长曝光 60–120s×40 帧 + 短曝光 10s×40 帧，L-Pro 滤镜，总积分约 1.5h，后期 HDR 融合核心。
- NGC7000 入门实战：Samyang 135mm F/2 + 改机单反 + iOptron SkyGuider Pro + Astronomik 12nm Ha 夹式，4min×45（ISO1600）≈3h，叠加 IC5070 同框。
- M51 进阶实战：Esprit 150 @1050mm + 单色相机 LRGB，L 36×300s / R 9×300s / G 12×300s / B 15×300s，合计 6h，城市边缘 Bortle 6–7 可出旋臂细节。
- M81+M82 实战：8″ F/4 牛反 @800mm + DSLR，3min×80（ISO1600）≈4h，中焦可把两者收入同一视场。

### 四季目标推荐 <a id="05-目标图鉴-四季目标推荐"></a>

> 难度：新手 ｜ 读者：深空天文拍摄新手与进阶爱好者，需要做季节拍摄计划、按可见窗口安排目标的人群 ｜ 标签：#目标图鉴 #季节 #星系季 #银河季 #规划

**摘要**：北半球深空目标随季节高度可预测：春季是「星系季」（M51/M81/M101 等），夏季是「银河季」（M8/M16/M17/NGC7000 等），秋季以仙女座星系与双星团为代表，冬季则是猎户座大星云与玫瑰星云等亮星云主场。建议优先选择当季过中天、地平高度高的目标，并避开月相与光污染干扰。

**适用场景 / 前置条件**：适用场景：制定月度/季度拍摄计划、选择适合当前器材与本地光污染等级（Bortle 等级）的目标。前置条件：了解本地纬度、大致光污染等级、可用器材焦距范围，并用 Stellarium 等星图软件确认目标可见窗口（过境时间与地平高度）。

**核心知识点**
- 春季（3–5月，星系季）— 银河面低、夜空黑暗，最适合拍摄星系：M51 涡状星系、M81 波德星系（常与 M82 同框）、M101 风车星系、狮子座三重星系（M65/M66/NGC3628）、M104 草帽星系、M64 黑眼星系。其中 M81/M82 在 2–5 月最佳（AstroBackyard 实测 Bortle 7  backyard 可拍）。
- 夏季（6–8月，银河季）— 银河核心升起，发射星云密集：M8 礁湖星云、M16 鹰星云（创生之柱）、M17 奥米伽星云、NGC7000 北美洲星云、面纱星云（东/西 NGC6992/NGC6960）、Rho Ophiuchi 星云；M8 在光污染下也能显出粉色辉光，M16 约 30 秒单帧即可见核心（城市 1–2 小时积分可出外围细节）。
- 秋季（9–11月）— 夜更长更凉，星系与星云混合：M31 仙女座星系（9 月最佳，整夜近天顶）、M33 三角座星系、双星团（NGC869/NGC884，英仙座，广角经典）、加州星云 NGC1499、心/灵魂星云（IC1805/IC1848）、吃豆人星云 NGC281、螺旋星云 NGC7293。M31 建议过中天（近天顶）拍摄以减少大气湍流与光污染。
- 冬季（12–2月）— 亮星云与星团主场，寒夜大气稳定：M42 猎户座大星云、玫瑰星云 NGC2237、M45 昴星团、马头星云（IC434）/火焰星云（NGC2024）、圣诞树星团与锥状星云 NGC2264、M1 蟹状星云、巴纳德环 Sh2-276。玫瑰星云（视星等约 9.0）对光污染较耐受，配合光污染滤镜效果更佳。
- 可见窗口（北半球中纬度，约 35°–50°N）参考：M81/M82 2–5 月；M51 3–5 月；M42 12–2 月（傍晚东方升起，整夜可拍）；M31 9–11 月（9 月夜幕降临即高悬）；NGC7000 夏季 6–9 月（与银河核心同在 Cygnus）；M8/M16/M17 6–8 月随人马座银河核心。
- 焦距/器材倾向：星系（小而暗）多用中长焦（800–2000mm）；银河与大面积星云（M8/M42/NGC7000/M31/M33）多用广角至中焦（100–600mm）；玫瑰/马头/锥状等中等目标用中焦（400–1000mm）。
- 注：加州星云 NGC1499 在部分资料中归类为秋季目标（位于英仙座），与用户「冬季」分组略有出入；其最佳可见期通常在夏末至秋季，与 NGC7000 类似可在夏秋过渡期拍摄[不确定，季节归属见来源分歧]。

**注意事项**
- 月相：拍摄深空（尤其星系、暗弱星云）尽量选新月前后数日；夏/秋拍摄需避开满月强辉光。
- 光污染：星系（M101/M33 等低面亮度目标）对光污染极敏感，建议 Bortle 4 以下暗空或加窄带/光污染滤镜；M8、玫瑰星云等亮目标在 Bortle 6–8 城市仍可拍。
- 目标高度：目标过中天（接近天顶）时大气消光最小、湍流最低，画质最佳；避免在目标地平高度 <30° 时长时间曝光。
- 夜长与温度：冬季夜长利于积分但低温影响电池与结露，需备露凝带/除露与保温；夏季夜短，需提高单帧效率或利用窄带。
- 季节不是绝对：同一目标在不同月份的地平高度变化明显，务必用 Stellarium 等软件确认当年具体过境时间后再规划。

**示例**
- 春季一晚计划示例：3 月下旬 21:00，先拍 M81+M82（中焦 800–1000mm，4 小时积分），后转 M51（同焦距，星系季经典）。
- 夏季一晚计划示例：7 月新月期，用 135mm 镜头 + 星野 tracker 拍 NGC7000 + 鹈鹕星云（Ha/双窄带滤镜，3 小时），再用中焦拍 M8/M16 宽场。
- 冬季一晚计划示例：12 月，APO 折射镜（400–600mm）拍 M42 + 奔跑者星云 NGC1977（长/短曝光各一组做 HDR），再补拍玫瑰星云（窄带 Ha 更佳）。

## 06-选址与环境

### 光污染地图与Bortle <a id="06-选址与环境-光污染地图与bortle"></a>

> 难度：新手 ｜ 读者：刚入门、准备第一次出摊或寻找拍摄点的深空爱好者 ｜ 标签：#选址 #入门 #光污染 #Bortle

**摘要**：光污染地图（如 lightpollutionmap.info）与 Bortle 等级是评估拍摄点天空暗度的核心工具。Bortle 1 代表极致暗空，9 代表市中心重度光害；深空拍摄建议尽量 Bortle 4 及以下，城市周边可用窄带滤镜在 Bortle 6~8 仍出片。

**适用场景 / 前置条件**：适用场景：选择拍摄地点、判断本地是否值得架设设备、规划长途追星行程。前置条件：了解自己的经纬度或目标地点。

**核心知识点**
- Bortle 暗空分类法由 John Bortle 于 2001 年在《Sky & Telescope》发表，共 1~9 级，数字越小天空越暗。
- Bortle 分级速记：1=完美暗空（银河亮到投下阴影）；2~3=真正暗空/乡村；4=乡村郊野（银河清晰）；5=郊外城乡过渡；6=亮郊/近郊；7=城郊；8=城市；9=市中心。
- 配套量化指标 SQM（夜空质量仪，单位 mag/arcsec²）：Bortle 1≈21.7~22，Bortle 4≈20.5~21，Bortle 6≈19，Bortle 9≈<17。
- 常用光污染地图站点：lightpollutionmap.info / lightpollutionmap.app（基于 World Atlas 2015/Falchi 数据），可查任意坐标的 Bortle/SQM 与银河可见性。
- 城市周边可用窄带（Hα/OIII/SII 或双窄带）滤镜压制光污染：只放行发射线附近极窄波段，对街道钠灯/汞灯连续谱抑制显著，Bortle 6~8 也能拍发射星云。
- 窄带对反射星云、星系几乎无效（它们靠连续谱反射/恒星光），城市里拍星系仍建议去 Bortle 4 以下或等无月夜。

**注意事项**
- 地图数据为卫星反演的平均背景亮度，局部树荫、地面灯、地平线附近辉光会让实际体验差于地图数值，务必到现场用 SQM 或手机测光复核。
- Bortle 数值随月相、大气透明度、积雪（雪地反光增亮）波动，并非固定不变。
- 不要把'地图显示暗'等同于'适合拍'：还需同时看视宁度、云量、灰霾与wind。
- 窄带滤镜会显著改变色彩平衡，后期需做窄带配色（SHO / HOO 等）与连续谱校准，新手需预留学习成本。

**示例**
- 出摊前：打开 lightpollutionmap.app，搜索拍摄点坐标，查看 Bortle 等级与 SQM；若显示 Bortle 7 且目标是 M42 猎户座大星云，可上双窄带滤镜在城郊出摊。
- 长途追星：在地图上沿环线向外找 Bortle 3~4 的暗空点（常位于山地、保护区），对比车程与天气，选择性价比最高的点位。
- 滤镜选择：只拍 HⅡ区发射星云→单 Hα 或 Hα+OIII 双窄带；拍行星状星云→加 OIII；想保留细节又抗光害→双窄带（如 Optolong L-eXtreme/L-Ultimate）。

### 月相/季节窗口/远程台 <a id="06-选址与环境-月相-季节窗口-远程台"></a>

> 难度：进阶 ｜ 读者：需要按月份规划目标、安排新月/满月拍摄策略，或考虑租用远程台的深空爱好者 ｜ 标签：#月相 #季节窗口 #远程台 #规划

**摘要**：月相直接决定夜空背景亮度：宽带（彩色/LRGB）怕月，星系应在新月前后（月相<30%）拍摄；窄带（Hα/OIII/SII）几乎不受月光影响，可在接近满月时拍发射星云。各深空目标有固定季节窗口，远程台（智利阿塔卡马、国内高海拔台址）提供稳定暗空与高透明度。

**适用场景 / 前置条件**：适用场景：制定年度拍摄计划、新月窗口排期、考虑远程台托管。前置条件：已掌握光污染与天气判断基础。

**核心知识点**
- 月相影响：满月时夜空背景比新月亮数十倍；月照会淹没宽带弱目标（星系、反射星云）。经验法则：月相照明度<30%（新月前后约 1 周）适合拍星系；30%~70% 可拍较亮目标；>70%（接近满月）只建议窄带拍发射星云/行星状星云。
- 窄带抗月：Hα/OIII 滤镜只放行发射线窄带，月光作为连续谱被大幅压制，因此满月期也能拍 M42、M27、NGC 星云等发射体；但月光下的窄带背景仍略升，需加长总曝光。
- 季节窗口（北半球大致）：冬季（12~2月）猎户座/金牛座发射星云（M42、IC434、昴星团）；春季（3~5月）星系季（M51、M81/82、室女座超星系团、M104）；夏季（6~8月）银河星云（M8、M20、M16、M17、银心）；秋季（9~11月）仙王/仙女发射与星系（M31 仙女座、NGC7000、北美洲星云）。
- 目标高度角：优先在目标过中天、高度角>40°~50° 时拍，大气质量小、透明度好；用 Stellarium/天文通算可见弧段与最佳日期。
- 远程天文台—智利：阿塔卡马沙漠（如 ChileScope、DeepSkyChile、Obstech El Sauce）以 90%+ 晴夜率、极低湿度、稳定 seeing 著称，多为全自动托管，可远程控制。
- 远程天文台—国内：高海拔暗空台址如云南丽江/太清华台、西藏阿里、青海冷湖（赛什腾山，光害极低、晴夜多）等，国内爱好者可通过托管或租赁使用；冷湖近年因暗空保护受关注。

**注意事项**
- 季节窗口受纬度影响大：南半球季节相反，远程台（智利）与国内可见目标不同，规划前确认台址纬度。
- 远程台并非'随时能拍'：仍有云、风、月的窗口限制，且设备排队、网络中断、结露等风险需纳入排程。
- 月相只影响背景亮度，不消除光污染；城市周边即便新月，宽带拍星系仍吃力。
- 目标过中天高度角过低（<30°）时大气消光与视宁度下降明显，宁可等其季节上移。
- 远程台托管涉及费用、时区、数据安全与合同，[不确定]具体报价与可用性以各运营方当年公告为准。

**示例**
- 新月排程：查月相日历，标记新月±3天窗口专拍 M51/M81 等星系（LRGB）；满月周改用双窄带拍 M27/M57 行星状星云。
- 季节示例：4月安排星系季拍 M104（有望远镜高度角过中天），8月安排银心区 M8/M20 窄带。
- 远程台入门：先试用 itelescope/ChileScope 等按小时租赁，验证工作流后再考虑长期托管于冷湖或智利。

### 视宁度/透明度/云量 <a id="06-选址与环境-视宁度-透明度-云量"></a>

> 难度：进阶 ｜ 读者：需要判断当晚是否适合出摊、如何读气象预报的深空与行星拍摄者 ｜ 标签：#天气 #视宁度 #透明度 #云量 #入门

**摘要**：决定一夜成败的三大气象要素是视宁度（seeing，大气湍流导致的星点抖动，单位角秒）、透明度（transparency，大气洁净/水汽程度）与云量（cloud cover）。常用工具：天文通（微信小程序/App）、ClearOutside、Windy；其中视宁度好利于高倍行星与小星点，深空更看重透明度与无云。

**适用场景 / 前置条件**：适用场景：每次出摊前的'今晚能不能拍'决策、远程台任务排程。前置条件：知道拍摄点的经纬度（手机定位即可）。

**核心知识点**
- 视宁度（seeing）：大气湍流使星点像在不停抖动，用 FWHM 角秒衡量。优秀 seeing≈0.5"~1"（罕见），一般好天≈1"~2"，差时>3"~4"。对行星/小星点分辨率影响最大，深空长曝光可部分平均掉抖动但高 seeing 仍更利落。
- 透明度（transparency）：大气中水汽、尘埃、灰霾越少透明度越高，星更亮、信噪比更好。常分 Poor/Fair/Good/Excellent 或百分比；灰霾/沙尘天后透明度骤降。
- 云量（cloud cover）：晴空比例，0% 为全晴。注意低云、高云、雾的区别——高卷云肉眼难辨却会毁掉窄带与弱目标；看卫星云图与云底高度更可靠。
- 天文通（twtapp.com / 微信小程序）：整合晴天钟 + ECMWF 多模型小时预报，给出观星指数、云量、透明度、空气质量、月相、光污染，适合国内一键判断。
- ClearOutside（clearoutside.com）：天文学家给天文学家做的 7 天逐时预报，强调云量（低/中/高/总云），并给 seeing、透明度、月相、湿度、露点，界面为'天文专用'。
- Windy（windy.com）：强在风场、云层、湿度与急流；有社区插件（astronomy-seeing）用急流风速(>200hPa)与地面风估算 seeing 角秒与透明度评分，适合看大风/急流导致的坏 seeing。

**注意事项**
- seeing 数只是模型估算，实际以现场对焦后的星点 FWHM 为准，预报好也可能现场翻车。
- 湿度接近露点易结露，需带加热带/除露带，不能只看云量。
- 高云（卷云）常被云量预报低估，肉眼看是'晴'但拍摄已废，务必结合卫星云图。
- 城市灰霾天透明度差，深空弱目标信噪比大跌，不如改拍月亮/行星或放弃。
- Windy 默认是通用气象，astronomy-seeing 为第三方插件，读数需结合经验，勿盲信单一来源。

**示例**
- 国内日常：打开微信'天文通'小程序→输入地点→看观星指数与逐时云量/透明度曲线，指数≥80 且无高云即可出摊。
- 严谨排程：ClearOutside 查当晚低云=0%、seeing=Good、透明度=Good、湿度低于露点 10% 以上，再决定架设备。
- 判断坏 seeing：Windy 看高空气流强、地面大风，或急流插件显示 seeing>3"，行星拍摄应改期，深空可勉强但星点偏软。

### N.I.N.A 使用要点 <a id="07-软件工具-n-i-n-a-使用要点"></a>

> 难度：进阶 ｜ 读者：已拥有赤道仪/相机/导星设备、希望用一台 Windows 电脑完成从对星到拍摄全流程自动化的深空摄影者；也适合从 APT、SGP 等迁移的进阶用户。 ｜ 标签：#软件 #NINA #ASCOM #序列 #自动化 #深空拍摄

**摘要**：N.I.N.A（Nighttime Imaging 'N' Astronomy）是一款免费、开源、模块化的 Windows 深空拍摄控制软件，覆盖对星、构帧、对焦、居中、解析、导星与序列拍摄全流程。它通过 ASCOM 平台连接几乎所有设备，并支持插件生态与高级序列（Advanced Sequencer）实现无人值守自动化；新手可用内置向导快速上手，进阶用户用触发器/条件实现复杂流程。

**适用场景 / 前置条件**：适用场景：DSO（深空天体）长曝光叠加拍摄、马赛克拼接、窄带/宽带多目标自动计划。前置条件：Windows 10/11 64 位；需先安装 ASCOM Platform（设备统一接口层）及对应硬件的 ASCOM 驱动（相机、赤道仪/镜塔、电调焦、导星相机、滤镜轮、天平/穹顶等）；导星与解析需配合 PHD2 与 ASTAP/PlateSolve2。当前主线版本为 3.x（如 3.0.x/3.2.x nightly），3.0 起自动对焦、序列器、解析、导星、构帧向导等均有重大增强。

**核心知识点**
- 设备连接统一走 ASCOM：Options > Equipment 下分别添加 Camera、Telescope(Mount)、Focuser、Guide、Filter Wheel、Rotator、Weather、Safety Monitor 等；相机若默认不支持需先装 ASCOM 平台与厂商驱动。
- 拍摄流程标签（Tabs）：Imaging（拍摄/取景）、Sequence（序列）、Equipment（设备状态）、Options（设置）等，构成一条龙工作流。
- Framing Wizard（构帧向导）：输入目标后可在画面中预览视场、旋转角、构图，并一键 Slew+Center 居中。
- 自动对焦（Auto-Focus）：基于星点 Half-Flux Radius / 对比度检测，3.0 起支持多种曲线拟合方法并新增对比度检测对焦（contrast detection AF）；含 backlash 补偿（分两种可选行为）。
- 解析对齐（Plate Solving）：内置 Platesolve 设置，可调用 ASTAP、PlateSolve2、本地/在线求解器做居中（Center After Slew）与 GoTo 校准。
- 导星（Guiding）：原生集成 PHD2（也可 MetaGuide），序列中自动 Start/Stop Guiding 并接收导星状态。
- 高级序列（Advanced Sequencer）：由 Sequence Start / Target / End 三段组成，可用触发器（Trigger）、条件（Container/Condition）、循环（Loop）编排复杂流程（如先拍亮场预热、到中天翻转 Meridian Flip 后继续、按温度/湿度切换计划），可存为 XML 模板复用。
- 插件生态：通过 Plugin Manifest Repository 在应用内插件页直接下载安装（如 Image Planner、Orbitrary、Safety Monitors、Dome 控制等），扩展官方未覆盖的专用功能。
- Planetarium 集成：可与 Stellarium、SkySafari 等星图联动发送/接收目标坐标，辅助规划与 GoTo。

**注意事项**
- 务必先装 ASCOM Platform 与对应驱动，再在 N.I.N.A 内添加设备；驱动版本不匹配会无法连接或掉线。
- Nightly（每夜构建）版本含新特性但可能不稳定，正式拍摄建议用稳定 Release 而非 early nightly。
- Meridian Flip（中天翻转）阈值与回中（Settle）时间要设置合理，否则翻转后可能丢失导星或撞击镜筒限位。
- 远程/无人值守前，务必配置 Safety Monitor 与断电/云量保护，避免设备受损。
- 插件来自社区仓库，安装前确认来源与兼容性，避免与当前版本冲突。

**示例**
- 推荐起步流程：Equipment 连好设备 → Framing Wizard 选目标并居中 → Auto-Focus 跑一次 → Sequence 建简单序列（如 L 各 30×300s、Gain/Offset 设定）→ 启动并开 PHD2 导星。
- 进阶自动化：Advanced Sequencer 中 Sequence Start 加‘唤醒设备/平场’触发器，Target 段放‘亮场循环+中天翻转条件’，Sequence End 加‘停导星/收镜/关机’；存为 XML 模板，多夜复用。
- GoTo 校准：在 Platesolve 中选 ASTAP，执行‘Center After Slew’，N.I.N.A 会解析当前画面并微调赤道仪指向，将目标拉到画面中心。

### PHD2 导星软件 <a id="07-软件工具-phd2-导星软件"></a>

> 难度：进阶 ｜ 读者：使用导星相机+导星镜/主镜离轴导星、需要提高跟踪精度（压低 RA/Dec 漂移与周期误差）的深空摄影者；通常与 N.I.N.A、SGP、APT 等拍摄软件联动。 ｜ 标签：#软件 #PHD2 #导星 #赤道仪 #周期误差 #NINA

**摘要**：PHD2（Open PHD Guiding）是免费开源的导星软件，负责锁定一颗（或多颗）导星并向赤道仪发送修正指令以消除跟踪误差。其核心由‘星点搜索/匹配算法’（推荐 Multi-star 多星）与‘导星算法’（RA 常用 Hysteresis/Predictive PEC，Dec 常用 Resist Switch/Lowpass）组成；常见故障多为校准不当、掉星（Star Lost/Low SNR）与周期误差未抑止，可通过重新校准、调曝光、开 PPEC 解决，并可与 N.I.N.A 通过 ASCOM/外部导星无缝联动。

**适用场景 / 前置条件**：适用场景：任何需要导星的深空长曝光；支持 ASCOM（Windows）与 INDI（Linux/树莓派）设备。前置条件：导星相机（如 ASI 120MM 系列等）+ 导星镜或主镜 OAG；赤道仪已做极轴对齐与基础平衡；导星软件需与拍摄软件处于同一台电脑或通过网络（例如 N.I.N.A 用 External Guider/PHD2 的 ASCOM 服务器）连接。版本：稳定版约 2.6.x（开发版可见 2.6.13dev 系列）。

**核心知识点**
- 导星算法（Guide Algorithms）：RA 轴推荐 Hysteresis（滞回，响应快且稳）或 Predictive PEC（预测式周期误差修正）；Dec 轴因只需消除漂移，常用 Resist Switch / Lowpass / LowPass2（阻尼强，抑制锯齿）。每个算法有参数控制如何将星点偏移换算成修正量。
- 星点搜索/匹配：Multi-star（多星）算法利用辅助星点细化导星星移动、降低抖动，官方称‘几乎不会使导星变差’；另有 Auto、Static、Dynamic 等模式。
- 校准（Calibration）：首次使用或换设备/纬度后必须校准，PHD2 会在 RA/Dec 两个方向小幅移动以测量像素标度、正交性与回差（backlash）；校准数据可保存复用。
- PPEC / Periodic Error Correction：部分赤道仪支持持久化周期误差修正（在赤道仪或 PHD2 内训练并保存），长期降低 worm 周期误差。
- 关键状态指标：RMS（总导星误差，角秒）、RA/Dec 误差曲线、曝光时间、SNR；RMS < 1″ 通常即可接受，越接近极轴精度越高越好。
- 与 N.I.N.A 联动：N.I.N.A 的 Guiding 设 PHD2（External Guider/Phd2 服务器），N.I.N.A 可在序列中自动 Start/Stop 导星、读取 RMS 并在掉星时告警；亦可让 N.I.N.A 做居中后把导星交给 PHD2。
- 曝光与信噪比：导星曝光一般 1–3 秒，以让导星 SNR 足够（> 刚过阈值）且不因拖线过曝；弱星环境可加长曝光或换更亮导星。

**注意事项**
- Star Lost – Low SNR：多因导星太暗/曝光过短/焦距太长导致星点 SNR 不足；解决——选更亮导星、加长曝光、检查导星镜/主镜焦点与跟踪是否稳定。
- 校准失败/走形：常因校准步长(calibration step-size)不匹配或大风吹动；可在 Advanced Settings > Guiding 调整 calibration step-size，或重选画面中心附近的导星重新校准。
- 周期误差（Periodic Error）过大：先做机械调齿（gear meshing）与极轴精对；再开 PPEC 或在导星算法用 Predictive PEC；不要仅靠导星硬扛大周期误差。
- Dec 轴选错算法：给 Dec 用 RA 型低阻尼算法易产生‘锯齿/过冲’，应改用 Resist Switch/Lowpass 类。
- 导星与拍摄软件连接管理：避免在 N.I.N.A 与 PHD2 中重复 Start Guiding，统一由拍摄序列控制启停。
- 更换焦距/减速比/导星镜后必须重新校准，否则修正方向/标度错误会越导越偏。

**示例**
- 推荐设置：RA=Hysteresis（默认参数即可，必要时调 min move），Dec=Resist Switch；星点匹配=Multi-star；导星曝光=2s（视 SNR 调）。
- 掉星排查流程：PHD2 报 Star Lost → 看 SNR 与曲线 → 若 SNR 低则加曝光/换亮星 → 若校准老失败则重选中心导星并校准 → 确认极轴与平衡无问题后续拍。
- N.I.N.A 联动：N.I.N.A 的 Guiding 选择 PHD2，序列里放‘Start Guiding’；居中(Center After Slew)完成后 PHD2 接管导星，N.I.N.A 实时显示 RMS 并在异常时暂停。

### 规划与解析工具 <a id="07-软件工具-规划与解析工具"></a>

> 难度：新手 ｜ 读者：需要‘拍前规划（何时、朝哪、构图）’与‘拍中解析对齐（确认指向、GoTo 校准）’的所有深空摄影者，从刚入门到做马赛克/远程天文台的高手都依赖此类工具。 ｜ 标签：#软件 #ASTAP #PlateSolve2 #Stellarium #SkySafari #解析 #规划

**摘要**：深空工作流有两类关键辅助软件：解析（Plate Solving）类如 ASTAP、PlateSolve2，用来把一张照片反算出精确天球坐标，实现自动居中、GoTo 校准与拼接；规划（Planetarium）类如 Stellarium、SkySafari，用来模拟夜空、查看目标高度/时间窗、做构图与（通过 ASCOM/INDI）控制赤道仪。两者常与 N.I.N.A 集成——N.I.N.A 调用 ASTAP 做 Center After Slew，Stellarium/SkySafari 把目标发给 N.I.N.A 去 Slew。

**适用场景 / 前置条件**：适用场景：目标选取与可视时间窗规划、导星/主镜指向校准、多目标序列排序、马赛克视场预览、远程天文台无人值守。前置条件：ASTAP 需下载星表数据库（如 G17 等，依视场大小选择；大视场用较小库、小视场用大库以提高成功率）；PlateSolve2 通常随 Sequence Generator Pro 等提供或单独安装并配置星表；Stellarium/SkySafari 需设置观测地经纬度、时区，并通过 ASCOM/INDI 或网络插件连接赤道仪。

**核心知识点**
- ASTAP（Astrometric STAcking Program）：免费、开源的解析+叠加程序，采用星点‘四面体(quad)/三角形(triple)’模式识别算法做线性天文测量解（6 个 plate constants），对旋转、缩放、翻转不敏感；可解析 FITS 及导入 RAW(DSLR) 图像，也能叠加。视场越小越需更大星表。
- ASTAP 在 N.I.N.A 中的用法：Options > Platesolving 选 ASTAP，序列/构帧向导用‘Center After Slew’自动把目标拉到画面中心，并可用于‘GoTo 校准’提升赤道仪指向精度。
- PlateSolve2：经典解析器（常随 SGP 提供，或由 PlaneWave/Diffraction Limited 分发），本地求解需配星表；可与拍摄软件配合做居中与校准，适合已有 SGP 工作流的用户。在线盲解可选 Astrometry.net。
- Stellarium：免费开源虚拟天文馆（3D 星空），可设观测点、看目标高度曲线与可观测时间窗、预览构图；通过 Stellarium Scope / ASCOM 等可控制赤道仪并和 N.I.N.A 互发坐标。
- SkySafari（8 Plus/Pro 等付费版）：星表庞大、规划与多视场(Multiple FOV)功能强、含望远镜控制，适合认真规划与现场/远程控制；可与 N.I.N.A 等共享目标。
- 规划要点：查目标‘高度>30°且避开地平线遮挡’的时间窗、月相/光污染、透明度和视宁度；用 FOV 指示圈确认构图与是否需马赛克。
- 解析校准流程：Slew 到目标 → 拍一张 → 解析 → N.I.N.A/软件据解析结果微调赤道仪使目标居中；重复一次可把指向误差压到角秒级。

**注意事项**
- ASTAP 星表选错：视场小却装大库会慢/易失败，视场大却用小库会搜不到；按焦距与视场选合适星表（如 G17）。
- 解析失败常见原因：曝光不足/星点过少(<30 颗时模式识别变难)、图像旋转未告知、坐标初始猜测偏差太大；可先粗略 Slew 再解析或改用在线盲解。
- Stellarium/SkySafari 的观测地点与时区务必设对，否则高度曲线与升起/落下时间全错。
- 望远镜控制连接前确认赤道仪已极轴对齐且限位安全，避免软件 Slew 撞限位。
- PlateSolve2 与 ASTAP 不能混用星表路径，分别配置好各自数据库位置。

**示例**

## 08-FAQ

### 高频FAQ汇总 <a id="08-faq-高频faq汇总"></a>

> 难度：新手 ｜ 读者：全体爱好者 ｜ 标签：#FAQ #拍摄 #入门 #结露 #拖线 #跟踪 #平场 #电调焦 #偏色 #电源 #极轴

**摘要**：本文汇总深空天文拍摄中最常遇到的 8 类故障现象（拖线/星点拖尾、结露除雾、跟踪漂移、平场不均、电调焦回差、色彩偏色、电源不足、极轴不准），每条给出明确结论与可立即执行的一句话操作。结论先行：绝大多数成像问题都可用「精确对极轴 + 良好平衡 + 正确校准帧 + 稳定供电」四大基础解决。

**适用场景 / 前置条件**：适用于使用赤道仪/星野赤道仪+相机（DSLR 或冷冻 CCD/CMOS）进行深空长曝光拍摄的爱好者。前置条件：已完成基本器材搭建，但在实拍中频繁出现星点拉长、起雾、掉线、色彩异常等现象，需要快速排查与处置。

**核心知识点**
- 【拖线/星点拖尾】问题：星点被拉成线段或椭圆，而非圆点。结论：全场同一方向拉长多为极轴/跟踪误差或导星失败；局部或单星拉伸多为风振、机械松动、导星脉动；缩短曝光、改善导星与抗风可消除，后期可用 BlurXTerminator 修正。一句话操作：先缩短单帧曝光并复查 PHD2 导星 RMS（深空建议 <1"），风大时加防风罩或降低曝光时间。
- 【结露除雾】问题：物镜/镜头起雾，画面中心渐暗、星点渐渐消失。结论：当镜面温度低于空气露点即会结露，必须用加热带将镜筒温度维持在露点之上 2–3°C；提前预热、控湿、防风均可延缓结露。一句话操作：在物镜前端套上加热带（dew heater）+ 控制器，开局就开启，设定温度略高于环境温度 2–3°C。
- 【跟踪漂移】问题：长曝光后星点缓慢漂移、整体被拉成长条。结论：多因极轴偏差、配重不平衡、周期误差(PE)未校准或导星未校准；先做精确极轴，再检查平衡与导星校准。一句话操作：用漂移法/电子极轴镜/platesolving 把极轴误差压到 <5'（目视）或 <2'（深空），并重新运行导星校准。
- 【平场不均】问题：画面渐晕、四角偏暗、出现尘埃黑点。结论：由光学渐晕、灰尘、传感器/滤镜响应不均导致，须拍平场帧(Flat)并配平场暗场(flat dark)校准；若平场后仍有明显不均，多为平场本身亮度/对焦点/灰尘状态变动。一句话操作：保持同一光学布局拍平场（均匀光源、亮度约占满阱 50%），并配同参数平场暗场用于校准。
- 【电调焦回差】问题：对焦来回移动后焦点不一致、星点始终偏软。结论：电调焦（如 EAF）存在机械回差，需开启回差补偿/过冲策略，并使最后合焦步骤统一朝同一方向逼近。一句话操作：在控制软件开启 Backlash/Overshoot 补偿（如 N.I.N.A. 的 Overshoot），每次合焦都从同一方向逼近目标位置。
- 【色彩偏色】问题：整体偏红/绿/蓝，或星点颜色怪异。结论：多因白平衡设置不当、未做本底/平场校准或后期色彩失衡；RAW 拍摄 + 合理白平衡 + 校准帧可避免前期偏色。一句话操作：DSLR 用日光白平衡或拍自定义白平衡、全程 RAW，处理时用平场+暗场校准并做色彩平衡(WB)校正。
- 【电源不足】问题：设备随机掉线、赤道仪抖动、相机失联。结论：多为负载下供电电压跌落（线损/电源功率不足）、USB 供电不稳或接地环路；需足功率电源、加粗线材、统一接地。一句话操作：用 ≥ 设备总功耗 1.5 倍的 12V 电源，主供电线 ≥ AWG20，长距离更粗，必要时经集线盒（如 Pegasus）统一供电与接地。
- 【极轴不准】问题：即使短曝光星点也缓慢拉长/出现场旋转。结论：极轴偏差会引起场旋转与跟踪漂移，是深空长曝的最大杀手，必须精确对极轴。一句话操作：用极轴镜/漂移法/电子极轴（如 iPolar、SharpCap）将极轴误差控制在数角分内再开始拍摄。

**注意事项**
- 校准帧（暗场/平场/偏置）必须与正式拍摄使用完全相同的光学布局、温度与增益，否则校准无效。
- 加热带只需略高于露点即可，过热会在镜内产生热气流湍流，反而降低星点锐度。
- 回差补偿值需实测：过大导致合焦时间过长，过小仍会欠焦，建议用软件内置测量功能标定。
- 白平衡偏色前期可控，但深空窄带(Hα/OIII/SII)数据本就无真实色彩，偏色问题主要针对 L/RGB 与 DSLR 彩色。
- 供电线损随长度与线径急剧变化，长线务必加粗；多设备共用时留意总电流上限与接地环路噪声。
- 风振造成的拖尾无法通过极轴/导星解决，需物理防风或降低曝光。

**示例**
- 排查清单（星点拉长）：①看方向——全场同向→极轴/跟踪；局部→风/机械；②查导星 RMS 是否突增；③查配重平衡；④缩短曝光验证；⑤风大则加防风罩；⑥后期 BlurXTerminator 救急。
- 排查清单（画面变暗/起雾）：①摸物镜是否湿润；②确认加热带已开且温度高于环境；③检查环境湿度与温度差；④若已结露，关镜进车/室内回暖，勿用布擦冷镜面。

## 09-踩坑与复盘

### 新手常见踩坑与复盘 <a id="09-踩坑与复盘-新手常见踩坑与复盘"></a>

> 难度：新手 ｜ 读者：新手与进阶爱好者 ｜ 标签：#踩坑 #复盘 #入门 #结露 #拖线 #回差 #平场 #电源 #对焦 #极轴 #导星 #远程

**摘要**：深空拍摄的失败大多来自可预测的‘低级失误’而非设备不行：结露、拖线、回差、平场缺失、电源不足、对焦不实、极轴不准、导星掉星、远程失控是九大高频坑。多数问题可通过‘每次出摊前检查清单 + 冗余供电与线缆管理 + 校准帧随拍随存’规避，复盘价值远高于硬件升级。

**适用场景 / 前置条件**：适用于赤道仪+天文相机（或改装单反）的深空天体拍摄场景，包含 backyard 临场拍摄与远程/无人值守机位。前置条件：已完成基础器材搭建，正经历首次或多次失败，需要从失败案例中沉淀经验。

**核心知识点**
- 结露（镜头/改正镜起雾）→ 夜晚镜面温度低于空气露点，水汽在光学表面凝结，几小时后画面整体变暗、星点发虚。经验：无论天气看起来多晴，每次出摊都打开除露加热带（dew heater），功率调到‘镜面微温’即可，并用控制器而非满功率直连；高湿度/低温夜尤其要提前开。
- 拖线/星点拉线（star trailing）→ 常见机械与操作原因：极轴不准导致赤纬缓慢漂移甚至场旋；线缆从镜筒垂下被重力/风吹动产生‘拽线’（cable drag）；平衡不当、赤经回差使镜筒来回摆动；导星参数激进、曝光过短去追大气视宁度。经验：线缆在赤经/赤纬轴交汇处附近捆扎并留出松弛环；做系统刚性检查（双锁紧点、不用尼龙螺丝）；先用短时间不导星测试排除光学问题，再逐步加长导星曝光（≥3s）、降低 aggressiveness（约50%）。
- 回差（电调焦/赤道仪赤纬 backlash）→ 齿轮啮合存在空程，赤纬轴因导星修正频繁反向而‘先不动、再过冲’，导星曲线呈缓慢锯齿、星点变胖；电调焦（如 ZWO EAF）换方向后合焦位置漂移。经验：RA 略偏东重、Dec 略偏相机重，让齿轮始终压在同一齿面；PHD2 中将 Dec 设为单向（仅 North 或仅 South）引导；必要时微调蜗轮啮合或启用回差补偿（仅作小残余平滑，非救命）；电调焦每次反向后多走一点再回拉（或软件内设置 backlash 补偿值）。
- 平场失败/缺失（flat frames）→ 未拍或拍错平场，后期出现固定灰尘暗斑、暗角、明暗不均；平场光照不均、曝光不当、与亮场光轴/对焦位置不一致也会让平场失效。经验：每次换构衅/换滤镜/对焦改动后当夜补拍平场（白 T 恤法或平场盒，均匀光源）；平场数量足够（如 15–30 张）、不过曝不饱和；平场与亮场保持相同光学状态（同一对焦、同一器材姿态尽量一致）。
- 电源不足（brownout/掉电）→ 线径过细、线过长导致带载压降，电压低于阈值后相机/赤道仪随机断开、通信失败甚至整体重启，一整夜数据作废。经验：用足量线径、尽量短的供电线缆；用带电压/电流显示的电源盒（如 ASIAIR/UPB），监控 12V 实际负载电压；电池容量留余量并带保险与冗余；USB 集线器独立供电，避免从主机偷电。
- 对焦不实（missed focus）→ 手动对焦随意、换滤镜后未重对、温度下降导致焦距漂移，星点发虚、细节全无。经验：每次换滤镜都重新对焦；用 Bahtinov  masks 或电调焦+HFR/焦点曲线做自动对焦；低温夜设置定时重对焦（autofocus on temperature drop）；用亮星放大校验再开始亮场。
- 极轴不准（polar alignment error）→ 极轴偏差大时中心圆星、四角蛋形（场旋），长曝光必拖线；用‘三星 GoTo 校准’误当极轴校准是新手典型误区。经验：用极轴镜、漂移法或 SharpCap / 解析定位（plate solve）做真正极轴校准，目标误差 <10–15 角分；用 SharpCap 极轴前务必取出所有滤镜保证光路干净；每次搬运机位后重校。
- 导星掉星（guiding star lost）→ 导星镜盖未摘、导星星过暗/过饱和、导星镜与主镜 differential flexure（差动弯曲）、镜筒shows 风动导致导星失败、星点飞出窗口。经验：出摊前检查所有镜盖已摘；选亮且不饱和的导星星；副镜/抱箍/调焦座刚性不足时用 OAG（离轴导星）消除差动；风大时降曝光或加遮风；校准（calibration）做完再正式引导。
- 远程失控（remote rig lost control）→ 无人值守机位因 USB 集线器供电不足导致调焦器/相机掉线、网络中断、系统时间/定位错误使 GoTo 指向错误目标，半夜无法干预而整夜报废。经验：远程机位用独立供电的工业级 USB 集线器并固定接口；出发前核对系统时间与地理坐标；用看门狗/自动重连与断电重启；关键步骤（对焦、极轴、导星校准）先在本地验证再切远程；准备远程重启与告警。
- 其他高频细节坑 → 系统时间/定位与实地不符导致指向错误目标；坏视宁度（seeing）夜硬拍深空得到糊片；Barlow/增倍镜用于深空基本无益；未做自动化（NINA/SharpCap 序列）导致熬夜手动操作易出错。经验：建立出摊前检查清单（caps、时间、定位、平场、除露、平衡、线缆、供电、极轴、对焦、导星校准），把流程交给序列软件。

**注意事项**
- 除露加热带不要满功率直连，需用控制器调到镜面微温，否则可能烤坏镀膜或产生热湍流。
- 回差补偿（backlash compensation）只是小残余平滑手段，过度依赖会每次反向都过冲，应先从机械与单向引导入手。
- 平场必须与亮场保持相同光学状态（对焦、器材姿态），否则平场不仅无效还会引入新瑕疵。
- 电源线缆线径与长度直接决定带载电压，DIY 线缆务必核算载流，避免‘看似通电实则压降掉线’。
- 远程/无人值守机位务必有独立供电 USB  hub、看门狗与远程断电重启，否则一次掉线即整夜报废。
- 不要把‘三星 GoTo 校准’等同于极轴校准，二者解决不同问题。
- 所有结论来自社区经验与厂商文档，具体阈值（如极轴误差、回差毫秒数）因器材而异，实际操作以现场测试为准[不确定]。

**示例**
- 案例：一夜深空全废之‘忘开除露+细线供电’复盘。现象：前半夜星点正常，约 2 小时后画面整体变暗、星点发虚，同时相机开始随机断开。原因：①以为天气晴就未开除露加热带，改正镜结露；②从电源到赤道仪的供电线为以前短焦 setup 自制的 5 米细线，带载压降使电压跌破阈值，相机/USB 通信失败。复盘：此后每次出摊第一件事开除露控制器（微温档）；换用足量线径的短供电线并加电压监控；把‘除露 ON + 供电电压检查’写进出摊清单，同类问题再未发生。
- 案例：长焦拖线之‘拽线 + 赤纬回差’复盘。现象：300mm 以上焦距长曝光星点呈缓慢锯齿/蛋形，导星 RMS 看着不高但星点仍胖。原因：①相机供电与导星线从镜筒垂下，随重力与微风摆动产生 cable drag；②赤道仪赤纬回差大，导星反向修正时先空走再过冲。复盘：线缆在赤经/赤纬轴交汇处捆扎并留松弛环；RA 略东重、Dec 略相机重；PHD2 中 Dec 设单向引导；重做蜗轮啮合微调。处理后星点明显变圆，RMS 与实拍一致。
- 案例：远程机位掉线之‘USB 集线器偷电’复盘。现象：远程拍摄中 ZWO EAF 调焦器与相机频繁掉线，无法干预。原因：StarTech USB 集线器自身电源不足，带不动调焦电机与相机，温差大时更明显。复盘：更换为独立供电的工业级 USB 集线器并加固接口；加看门狗自动重连与远程断电重启；关键对焦/导星步骤先在本地验证。掉线率显著下降。
