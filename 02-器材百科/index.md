# 器材百科

* [智能望远镜：产品边界、文件导出与桌面后期前提](智能望远镜：产品边界、文件导出与桌面后期前提.md) - 区分厂商成图、已堆栈结果与逐张可处理数据，并在导出前确认型号、版本、文件状态和可回退副本。
* [常见智能望远镜参数规格对照与使用边界](常见智能望远镜参数规格对照与使用边界.md) - 将第三方市场规格快照用于型号识别和初筛；涉及功能、价格、导出或性能时回到厂商当前资料复核。
* [赤道仪选型](%E8%B5%A4%E9%81%93%E4%BB%AA%E9%80%89%E5%9E%8B.md) - 深空长曝光通常采用赤道仪或经验证的视场旋转补偿方案；选型应以摄影载荷定义、实际力矩、刚性、风和实拍星点为准。
* [关键附件](%E5%85%B3%E9%94%AE%E9%99%84%E4%BB%B6.md) - 关键附件连接光学、导星、对焦、供电与数据链路；选择时应核对实际光路、机械刚性、设备手册和带载验收。
* [成像光路：后截距、像圈与接口预算](%E6%88%90%E5%83%8F%E5%85%89%E8%B7%AF%EF%BC%9A%E5%90%8E%E6%88%AA%E8%B7%9D%E3%80%81%E5%83%8F%E5%9C%88%E4%B8%8E%E6%8E%A5%E5%8F%A3%E9%A2%84%E7%AE%97.md) - 用改正镜参考面、传感器面、附件长度和有效通光口径建立可验收的成像光路，避免把 55 mm 当作通用规则。
* [滤镜系统](%E6%BB%A4%E9%95%9C%E7%B3%BB%E7%BB%9F.md) - 滤镜分宽带（LRGB）与窄带（Hα/OIII/SII）；窄带能压低部分连续背景，选型还须考虑焦比、带宽、光路与目标。
* [天文相机选型](%E5%A4%A9%E6%96%87%E7%9B%B8%E6%9C%BA%E9%80%89%E5%9E%8B.md) - 按目标、光路、传感器、采样、噪声、温控和工作流选型；制冷 CMOS 常用于可重复长曝光，但不是所有场景的硬门槛。
* [望远镜选型](%E6%9C%9B%E8%BF%9C%E9%95%9C%E9%80%89%E5%9E%8B.md) - 从目标角尺度、焦距与传感器视场、口径、焦比、像场修正、机械稳定性和赤道仪能力综合选择主镜。
